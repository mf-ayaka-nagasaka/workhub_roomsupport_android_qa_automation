予約の参加者情報を表示できる

会議室の前のタブレットが、いま出ている予約の主催者と参加メンバーを、予約ごとの公開範囲に従って画面に出すまでを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝そのとおり出る確認、● 赤＝出ない・減る方の確認。

ルール① 出るとき・出ないとき

入室待ち・全公開・参加者3人 → 主催者と参加メンバーが出る
同じ予約に入室して利用中 → 出たまま変わらない
「予約情報の表示」が無効 → 出ない
当日の予約が無く空室 → 出ない
参加者が1人も登録されていない → 出ない

ルール② 公開範囲で出る中身が変わる

全公開 → 主催者の行＋名前＋「他1名」
主催者のみ公開 → 主催者の行だけ
非公開 → 1行も出ない

ルール③ 主催者の行（名前の決まり方）

予約を作った人が1行目に出る（所属の会社名は出ない）
日本語で「主催者」／英語で「Host」
作った人が参加者にいない → 先頭の人が主催者
人物の情報が5回とも取れない → 予約に入っている名前で出る
名前がどこにも無い → エリアごと出ない（赤カード①）

ルール④ 名前が並ぶ人数と対象

主催者だけ → 参加メンバーの行が出ない
従業員2人（上限の手前） → 2人が並ぶ
従業員3人（上限ちょうど） → 3人が並ぶ
従業員4人（上限の直後） → 3人までで止まる
ゲストが混ざる → 従業員の名前だけ並ぶ
ゲストだけ → 1人も並ばない
11人目にいる従業員 → 名前は出ないが「他N名」には数えられる（赤カード③）

ルール⑤ 「他N名」の人数

計4人・超過なし → 「他N名」の行が出ない
計5人・超過1人 → 「他1名」
従業員1人＋ゲスト2人 → 「他2名」
ゲスト3人 → 名前なしで「他3名」
英語表示 → 「+1 others」
参加メンバーの情報が5回とも取れない → 名前が出ず「他N名」に入る

ルール⑥ 氏名の言語

日本語表示 → 日本語の名前
英語表示 → 英語の名前
英語の名前が空 → その人だけ日本語の名前
英語の名前が「-」 → その人だけ日本語の名前

ルール⑦ 主催者の顔写真

写真の登録あり → 丸く切り抜かれて出る
写真の登録なし → 既定の人型
参加メンバーの名前には写真が付かない

ルール⑧ 他の会社（テナント組織）の予約

他の会社の予約 → 主催者は個人名でなく会社名、名前は1人も並ばず全員「他N名」

ルール⑨ 予約が切り替わる（終了・自動キャンセル）・画面を離れる

利用中に終了時刻を過ぎ、次の予約が続く → 主催者も名前も次の予約のもの
入室待ちが自動キャンセルされ、次の予約が続く → 次の予約のものに入れ替わる
利用中に終了時刻を過ぎ、次の予約が無い → 空室になって出なくなる
入室待ちが自動キャンセルされ、次の予約が無い → 出なくなる
自動キャンセルが無効のまま終了時刻を過ぎる → 出なくなる
次が非公開の予約 → 出なくなる
次が参加者のいない予約 → 出なくなる
非公開の予約（出ていない）→ 次が全公開 → 出るようになる
認証画面へ進んで操作せずに戻る → 離れる前と同じ表示

ルール⑩ 同じ予約のまま顔ぶれが変わる

従業員を1人追加 → 名前が並びに加わる
参加メンバーを1人削除 → 名前が並びから消える
ゲストを1人追加 → 並びは変わらず「他1名」が出る
ゲストを削除 → 並びは変わらず「他1名」が消える
人数が変わらない差し替え → 名前が入れ替わる（赤カード②）
作った人が参加者から外れる → 先頭の人が主催者

通し（実機で最後まで）

空室の部屋に予約が作られ、操作なしで主催者と参加メンバーが出る

「出ない」「思ったのと違う」の理由は、どこの話？

画面での見え方そうなっている場所
参加者情報が1行も出ない① 「予約情報の表示」が無効 ／ ① 空室（予約が終わった・自動キャンセルされた後で次の予約が無い） ／ ① 参加者が0人 ／ ④ 主催者の名前がどこにも無い ／ ⑦ 非公開
主催者の行だけが出て、名前も「他N名」も出ない⑦ 主催者のみ公開
参加メンバーの名前が1人も並ばない⑤ 並べる従業員が0人（主催者だけ／ゲストだけ／他の会社の予約）
名前が3人までで止まる⑤ 並ぶのは3人までと決まっている
ある従業員の名前だけ出ない② 11人目以降にいる ／ ② その人の情報が取れなかった ／ ⑤ 4人目以降にあたる
「他N名」の行が出ない⑥ 名前が出なかった人が0人
「他N名」の人数が、名前が出ていない人の数と合っている⑥ 参加者全員の数から、名前が並んだ人と主催者を引いている。② で取らなかった11人目以降もここに数えられる
顔写真が人型のまま③ 写真が未登録（取得に失敗したときの表示は画像表示ライブラリの責務のため対象外）
主催者の行に個人名ではなく会社名が出る④ 他の会社（テナント組織）の予約では、個人名ではなく会社名が出る
主催者の名前が、登録しているのと違う名前で出る② 情報を5回とも取れず、予約に入っている名前で出ている
英語表示なのに日本語の名前で出る④⑤ その人の英語の名前が未登録（空・「-」）
主催者の行に会社名が出ない④ 主催者の行には会社名を出さない（タイムラインの予約の詳細とは別）
