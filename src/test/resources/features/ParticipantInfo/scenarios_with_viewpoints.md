# language: ja
機能: 予約の参加者情報を表示できる
  会議室のドア前に常設されたタブレットのホーム画面で、いま表示している予約の主催者と参加メンバーを、予約ごとの公開範囲の設定に従って参加者情報エリアに表示する。合否は、画面にどの要素が出ているか・そこに何と書かれているかで判定する

  背景:
    前提 会議室タブレットは予約認証モードで設定されており、起動準備を終えてホーム画面を表示している

  # ※ 利用不可・利用時間外の表示（台帳 #15）、入室・退室などの操作中の表示（#28）、サードプレイスの予約（#29）、
  #   タイムラインの予約の詳細に出る主催者名（#24 #30）、ホームに着くまでの待ち時間（#8 #12 #26）は本機能では扱わない
