# language: ja
機能: 顔認証で利用者を特定できる
  会議室のドア前に常設されたタブレットのカメラ認証画面で、カメラに映った顔から利用者本人を特定し、特定結果を持って操作ごとの画面へ進む。解錠と入退室の更新はこの画面では行わず、特定結果を受け取った先の画面が行う

  背景:
    前提 会議室タブレットは予約認証モードで設定されており、顔認証オプションが有効になっている

  # ※ 認証に失敗したときの表示・認証待ちへの復帰・解錠デバイス未連携の表示は⑭の責務（台帳 #40・#41）。本機能では扱わない
  # ※ なりすまし防止の指示の内容・検知したときの扱いは⑰の責務（台帳 #45）
  # ※ 予約作成の画面・延長時間を設定する画面で行う操作と、その可否判定は㉒㉓の責務
