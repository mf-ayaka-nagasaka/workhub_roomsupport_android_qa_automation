起動時に予約データを準備してホームを表示できる

ログイン・組織選択のあと、読み込み画面からホーム画面に着くまでに、裏で何が順番に確認されるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝進めない・止まる確認。

ルール① 端末の登録・設定状態で行き先が決まる

登録・初期設定・名前/場所設定が全部済み → ホームへ
端末が未登録 → インストール確認が出る
初期設定ウィザードが未完了 → ウィザードへ
名前または設置場所が未設定 → 設定画面へ
オフラインで起動 → 読み込み画面のまま進めない（WiFiオフ／機内モード／SIM無効／不安定な回線／DNS失敗のいずれでも同じ）

ルール② 予約データの到着を待ってからホームへ進む

予約データが10秒以内に届く → 反映された状態でホームへ
予約データが10秒待っても届かない → そのままホームへ進み、届き次第自動で反映

ルール③ 予約データの状態でホームの見た目が決まる

予約がない → 空室状態で表示
予約はあるがまだ入室していない → 待機中状態で表示
入室済みの予約がある → 使用中状態で表示
予約はあるが入室可能時間の閾値に未到達 → 空室状態で表示
入室可能時間の閾値に到達した直後（境界値） → 待機中状態で表示
対象スペースが利用不可時間中 → 「利用時間外」状態で表示

通し（実機で最後まで）

起動準備から予約データを反映したホーム表示までが正常に完了する
