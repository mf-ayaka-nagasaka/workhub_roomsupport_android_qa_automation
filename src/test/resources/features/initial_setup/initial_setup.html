予約認証モードでの初期設定

認証方式を選んでから初期設定完了画面に着くまでに、裏で何が順番に起きるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

ルール① 認証方式を選ぶ

QR認証を選ぶ → ひな形選択に進む
顔認証を選ぶ → 有効化の手続きに進む
QR＋顔認証を選ぶ → 有効化の手続きに進む
方式選択中に終了 → 方式選択から再開

ルール② 顔認証を有効にする

有効化を完了 → ひな形選択に進む
有効化をキャンセル → 方式選択に戻る
手続き中にアプリが止まる → 最初からやり直し
有効化をスキップしようとする → できない
顔認証説明画面で終了 → 方式選択に戻る
有効化リクエスト送信後に終了 → 有効化から再開

ルール③ ひな形を選ぶ

テンプレートを選ぶ → 設定画面に進む
既存の設定を流用 → 設定画面に進む
手入力を選ぶ → 設定画面に進む
流用できる設定がない → 流用の選択肢が出ない
設定タイプ選択中に終了 → 設定タイプから再開
ひな型選択中に終了 → 設定タイプに戻る
コピー元選択中に終了 → 設定タイプに戻る

ルール④⑤ チェックして保存

全項目を入力して保存 → コピー確認に進む
認証方法を選んでいない → エラー
タブレット名が空 → エラー
スペースを選んでいない → エラー
パスワードと確認が違う → エラー
予約設定のないスペース → エラー

ルール⑥ コピーを登録

名前をつけてコピーする → 完了
コピーしないで進む → 完了
名前が空 → 登録ボタンが押せない

通し（最初から最後まで）

初回起動から予約認証モードで完了まで
