initial_setup ／ 全体マップ

予約認証モードでの初期設定

タブレットの初回起動から、認証方式を選び → 設定タイプを選び → 各種設定を入力して保存し → 初期設定を完了するまでの流れを1枚にしたもの。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

ルール① 認証方式を選ぶ

QR認証 → 設定タイプ選択に進める
QR＋顔認証 → 顔認証有効化へ
認証方式選択中に中断 → 再開で方式選択から

ルール② 顔認証を有効にする

有効化が承認される → 設定タイプ選択へ
有効化をキャンセル → 認証方式選択に戻る
説明画面で中断 → 再開で認証方式選択に戻る
有効化リクエスト後に中断 → 再開で有効化画面へ

ルール③ 設定タイプを選ぶ

テンプレート → テンプレの値で設定画面へ
カスタム → 手入力の設定画面へ
設定タイプ選択中に中断 → 再開でタイプ選択から
ひな型選択中に中断 → 再開で設定タイプ選択に戻る

ルール④ コピー元を選ぶ

コピー元を選ぶ → コピー値で設定画面へ
名称検索・利用タイプ・認証モードで絞り込み
不要な既存設定を削除できる
予約認証モードの端末がない → 一覧に表示なし
既存設定が0件 → コピー選択肢が出ない
コピー元選択中に中断 → 再開で設定タイプ選択に戻る

ルール⑤ 予約設定を確認して保存

予約設定があるスペース → 保存OK
予約設定なしのスペース → 保存が拒否される

ルール⑥ 必須項目をチェック

予約認証方法・タブレット名・スペース未入力 → エラー
パスワード不一致 → 保存が拒否される

ルール⑦ 親子連動（ON/OFFで子項目が出る）

自動ステータス更新ON → 自動キャンセル・延長が出る
自動ステータス更新OFF → 子項目が消えてデフォルトに戻る
自動キャンセルON → 時間＋前通知が出る
前通知ON → 前通知時間が出る
自動延長ON → タイミング＋時間が出る
終了前リマインダーON → 通知時間・繰返し・音が出る
リマインダー繰返し→回数指定 → 回数入力が出る
解錠ON → デバイスPickerが出る
解錠OFF → デバイスPickerが消える
常時接続ON → 対象デバイスPickerが出る
なりすまし防止ON → モード＋期間が出る
省エネ→カスタム → 条件Pickerが出る

ルール⑦ 単独切替・CheckBox・Picker

テナント従業員予約 → 不許可に切替
予約情報 → 非表示に切替
解錠タイミング → 選択肢を切替
機能制御を個別にON/OFF → CheckBox状態が変わる
予約作成ON → 解錠タイミング選択が出る
顔認証機能を個別にON/OFF → CheckBox状態が変わる
Pickerからデバイス・音を選ぶと選択値が反映

ルール⑧ 設定コピーの登録

識別名称を入力してコピー登録 → 完了
コピーしない → そのまま完了
識別名称未入力 → 登録ボタンが押せない

通し（実機で最後まで）

テンプレートで全動線 → 初期設定完了
コピーで全動線 → 初期設定完了

エラーの言葉で、止まった場所がわかる

画面に出る言葉止まった場所
予約認証の認証方法を選択してください⑤ 認証方法が未選択のとき
タブレット名を入力してください⑤ タブレット名が空のとき
空間を選択してください⑤ スペースが未選択のとき
パスワードが一致しません⑤ パスワードと確認パスワードが違うとき
{スペース名}は予約設定がされていません⑤ 予約設定のないスペースを選んだとき
