initial_setup ／ 全体マップ

予約認証モードでの初期設定

タブレットの初回起動から、認証のしかたを選び → 設定の始め方を選び → 各項目を入れて保存し → ホーム画面に着くまでの流れを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝うまくいかないときの確認。

ルール① 認証のしかたを選ぶ

QRだけ／QRと顔 の2つから選べる
選んだしかたで次の行き先が変わる
顔がもう使える組織 → この画面を飛ばす
選んでいる途中で止める → 同じ画面から再開

ルール② 顔を使う準備をする

説明を読んで進む → 申し込みが送られる
承認されるまでは先に進めない
開いたまま承認された → 先に進める
申し込みを取り消す → 前の画面に戻る
準備の途中で止める → 認証のしかたの画面に戻る
申し込んで待っている間にアプリを落とす → 開くと認証のしかたの画面
閉じている間に承認された → 開くと始め方の画面から

ルール③ 設定の始め方を選ぶ

ひな形／コピー の2つから選べる
選んだ始め方で次の行き先が変わる
元にできる設定が0件でもコピーは押せる → 次の画面で「0件」を知らせる
選んでいる途中で止める → 同じ画面から再開

ルール④ 使い方のタイプを選ぶ

5つのタイプから選べる
タイプを押すと確認が出る（実行／キャンセル）
実行 → ひな形の一覧を通らず入力画面へ
キャンセル → タイプを選ぶ画面に残る
選んでいる途中で止める → 認証のしかたの画面へ

ルール⑤ タイプごとの値が入る

タイプを選んで実行 → そのタイプの値が入った入力画面へ（カスタムは初期値）

ルール⑥ コピー元を選ぶ

コピー元を選ぶ → その値が入った入力画面へ
予約のしかたで使っている端末だけが出る
該当する端末が0件 → 出せるものがない
名前の順（あいうえお順）で並ぶ
名前で探す・タイプや認証で絞る・組み合わせる
大文字と小文字は別もの扱い → 当てはまらない
絞り込みをやめる → 元の一覧に戻る
どれにも当てはまらない条件 → 出せるものがない
確認して消す → 一覧から消える
確認でやめる → 消えない
最後の1件を消す → 一覧が0件になり、その旨が出る
コピー元の一覧が出てこない → エラー画面
選んでいる途中で止める → 認証のしかたの画面へ

ルール⑦ 前の画面に戻る

いちばん最初の画面には戻るボタンがない
どの画面からも1つ前に戻れる
戻って選び直す → 選び直した先へ進む

ルール⑧ 使う空間を選ぶ

予約の設定がある空間だけ選べる
選べる空間が0件 → 空間を選べない
出てきた空間を選んで保存できる

ルール⑨ 必ず入れる項目

必要な項目をすべて入れる → 保存できる
名前・空間・認証のしかた・カギが空 → 保存できない
合いことばと確認用が違う → 保存できない
足りない項目が複数 → まとめて知らせる
足りない項目が3つ以上 → 2つ出して残りは「他◯件」
直してもう一度保存 → 保存できる

ルール⑩ 数と文字数の決まり

いちばん小さい値ちょうど → 保存できる
0・マイナス・空 → 項目ごとの言葉で止まる
決まった範囲から外れた値 → 保存できない
文字数が上限以内 → 保存できる
文字数が上限を超える → 保存できない
隠した項目は見られず、もとの値で残る

ルール⑪ 各項目を入れる・切り替える

始め方ごとに最初から入っている値が違う
コピーしても名前と説明は引き継がない
親をONにすると、ぶら下がる項目が出る
親をOFFにすると隠れて、値がもとに戻る
カギを開けない → 機器の選択が隠れる
ゆるめの判定 → 切り替えの設定が隠れる
使い方のタイプで2台目の機器が出る／出ない
顔が使えない組織 → 顔のまとまりが出ない
単独の切り替えを変えると選択が変わる
タブレットでできることを1つずつ切り替える
すぐ入室をONにすると開けるタイミングが出る
顔が必要な操作を1つずつ切り替える
一覧から機器や音を選ぶと反映される
つなぎっぱなしの機器は複数選べる
入れかけで止める → 入れた内容は残らない

ルール⑫ 保存している間

保存中は画面を操作できない
続けて押しても保存は1回だけ
保存が終わると次の確認へ進む

ルール⑬ 仕上げてホームへ

名前を付けて残す → ほかの端末から使える
残さないを選ぶ → そのまま完了へ
名前が空 → 残す操作ができない
完了から進む → ホーム画面に着く
確認中に止める → 最初からやり直しにはならない

ルール⑭ 終わったあとの起動

終わった端末を起動 → この画面は出ない
終わっていない端末を起動 → 続きから
名前か空間が空 → ホームではなく入力画面

通し（実機で最後まで）

タイプを選んで最後まで → ホームに着く
コピーで最後まで → ホームに着く
カスタムで最後まで → 名前を付けて残す
終わったあとに再起動 → ホームに着く
