# language: ja
機能: 予約認証モードでの初期設定
  管理者がタブレットの初回起動時に、認証方式の選択・設定タイプの選択・
  各種設定の入力を行い、予約認証モードで初期設定を完了する。

  背景:
    前提 タブレットは初期設定が未完了の状態である

  # ────────────────────────────────────────
  # ルール①: 管理者はQRまたは顔認証方式を選択して初期設定を開始できる
  # ────────────────────────────────────────

  # @TestLevel: PresentationUnit (JVM / Turbine)

    もし 田中がQR認証を選択する
    ならば 設定タイプ選択ステップが表示される
