## ルールの洗い出しと正常系・異常系の分類

### 機能名: 予約認証モードでの初期設定
**機能概要:** 管理者がタブレットの初回起動時に、認証方式の選択・設定タイプの選択・各種設定の入力を行い、予約認証モードで初期設定を完了する。

---

### ルール①: 管理者はQRまたは顔認証方式を選択して初期設定を開始できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 認証方式選択後のページ遷移はViewModelのpage状態変化であり、実機描画なしでストリーム検証可能なため。

| 対象 | 認証方式 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | QR認証 | 🟢正常系：QR認証を選択 | 設定タイプ選択ステップに進める |
| 管理者 | 顔認証 | 🟢正常系：顔認証を選択 | 顔認証有効化フローに進む |
| 管理者 | QR＋顔認証 | 🟢正常系：QR＋顔認証を選択 | 顔認証有効化フローに進む |
| 管理者 | -（選択前） | 🟡例外系：認証方式選択中にアプリを終了し再起動 | 認証方式選択画面から再開される（進行状態: initializing） |

---

### ルール②: 顔認証を選択した管理者は、有効化を完了しなければ設定タイプ選択に進めない
**推奨テスト階層:** Application Unitテスト (JVM)
**割り振り理由:** 顔認証アクティベーションAPI呼び出し→完了判定→ページ遷移の一連のユースケースフローを通しで検証するため。

| 対象 | 有効化操作 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 有効化を確定 | 🟢正常系：顔認証の有効化を完了する | 有効化完了が表示され、設定タイプ選択ステップに進める |
| 管理者 | 有効化をキャンセル | 🟢正常系：有効化をキャンセルする | 認証方式選択ステップに戻る |
| 管理者 | 説明画面で中断 | 🟡例外系：顔認証説明画面でアプリを終了し再起動 | 認証方式選択画面に戻る（進行状態: initializingのまま） |
| 管理者 | 有効化リクエスト送信後に中断 | 🟡例外系：有効化リクエスト送信後にアプリを終了し再起動 | 顔認証有効化画面から再開される（進行状態: pendingFaceActivation） |

---

### ルール③: 管理者は設定タイプ（テンプレート／コピー／カスタム）を選んで設定を構成できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 設定タイプ選択後のページ遷移・データ適用はViewModelの状態変化であり、ストリーム検証で完結するため。

| 対象 | 設定タイプ | 既存設定 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | テンプレート | - | 🟢正常系：テンプレートを選択 | テンプレートの設定値が適用され設定画面に遷移 |
| 管理者 | コピー | あり | 🟢正常系：既存設定をコピーして適用 | コピー元の設定値が適用され設定画面に遷移 |
| 管理者 | カスタム | - | 🟢正常系：カスタムを選択 | 空の設定画面に遷移（手動で各項目を設定） |
| 管理者 | コピー | なし | 🔴異常系：既存設定が存在しない | コピー選択肢が表示されない |
| 管理者 | -（選択前） | - | 🟡例外系：設定タイプ選択中にアプリを終了し再起動 | 設定タイプ選択画面から再開される（進行状態: selectSetting） |
| 管理者 | テンプレート | - | 🟡例外系：ひな型選択中にアプリを終了し再起動 | 設定タイプ選択画面に戻る（進行状態: selectSettingのまま） |
| 管理者 | コピー | あり | 🟡例外系：コピー元選択中にアプリを終了し再起動 | 設定タイプ選択画面に戻る（進行状態: selectSettingのまま） |

### ルール④: 予約認証モードで保存するには、選択スペースに予約設定が登録されていなければならない
**推奨テスト階層:** Domain Unitテスト (JVM)
**割り振り理由:** スペースIDと予約設定の存在チェックはPure Kotlinのビジネスルール判定であり、Android依存ゼロで最も高速に検証できるため。

| 対象 | 認証モード | 予約設定 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 予約認証 | あり | 🟢正常系：予約設定が登録されているスペースを選択して保存 | 設定の保存が実行される |
| 管理者 | 予約認証 | なし | 🔴異常系：予約設定が未登録のスペースを選択して保存 | エラー「{スペース名}は予約設定がされていません」が表示され、保存されない |

### ルール⑤: 初期設定の保存には必須項目の入力と予約認証方法の選択が必要
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 各フィールドのバリデーション状態とエラー表示はViewModelのUiState変化であり、実機描画なしで検証可能なため。

| 対象 | バリデーション項目 | 入力状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 全項目 | すべて入力済み | 🟢正常系：必須項目をすべて入力して保存 | 保存処理が実行される |
| 管理者 | 予約認証方法 | 未選択 | 🔴異常系：予約認証方法を選択せずに保存 | エラー「予約認証の認証方法を選択してください」が表示される |
| 管理者 | タブレット名 | 空 | 🔴異常系：タブレット名を未入力で保存 | エラー「タブレット名を入力してください」が表示される |
| 管理者 | スペース | 未選択 | 🔴異常系：スペースを未選択で保存 | エラー「空間を選択してください」が表示される |
| 管理者 | パスワード | 不一致 | 🔴異常系：パスワードと確認パスワードが不一致で保存 | エラー「パスワードが一致しません」が表示される |

### ルール⑥: 初期設定の保存成功後、設定コピーの登録有無を選択して初期設定を完了できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** コピー登録選択→完了画面表示のUI状態遷移であり、ViewModelのストリーム検証で完結するため。

| 対象 | コピー選択 | 識別名称 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | コピーする | 入力済み | 🟢正常系：識別名称を入力してコピー登録 | 設定コピーが登録され、初期設定完了画面が表示される |
| 管理者 | コピーしない | - | 🟢正常系：コピーしないを選択 | コピーせずに初期設定完了画面が表示される |
| 管理者 | コピーする | 未入力 | 🔴異常系：識別名称を入力せずに登録を試みる | 登録ボタンが無効化されており登録できない |

### ルール⑦: ON/OFF切替で子項目の表示が連動する設定（初期設定画面）
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 親項目の切替に応じた子項目の表示/非表示はViewModelの状態変化であり、ストリーム検証で完結するため。

**前提:** 初期設定のウィザードで設定画面に到達した状態。設定タイプ（テンプレート/コピー/カスタム）の選択に応じて初期値が異なる。

**ネスト構造（画面表示・機能制御セクション）:**
```
自動ステータス更新 = 有効
├── 自動キャンセル = 有効
│   ├── 自動キャンセル時間（秒）
│   └── 自動キャンセル前通知 = 有効
│       └── 前通知時間（秒）
└── 自動延長 = 有効
    ├── 自動延長タイミング（分）
    └── 延長時間（分）
```

**ネスト構造（SE・通知セクション）:**
```
終了前リマインダー = 有効
├── 通知時間（秒）
├── 繰り返し = 回数指定
│   └── リマインダー回数（回）
└── リマインダー音（Picker）
```

**ネスト構造（デバイス・解施錠セクション）:**
```
解錠機能 = 解錠する
├── 解錠対象デバイス1（Picker）
└── 解錠対象デバイス2（Picker）※Enterprise/ThirdPlace/BillTenantのみ

常時接続 = 有効
└── 常時接続対象デバイス（MultiPicker）
```

**ネスト構造（顔認証セクション ※isFaceOptionActive時のみ表示）:**
```
なりすまし防止 = 有効
├── 防止モード（ハイセキュリティ/スムーズ）
│   └── 判定方法の自動切替 ※ハイセキュリティ時のみ
└── なりすまし防止期間
```

**ネスト構造（画面表示・機能制御セクション - 省エネモード）:**
```
省エネモード = カスタム
├── 開始バッテリー残量（Picker）
├── 開始温度状態（Picker）
├── 停止バッテリー残量（Picker）
└── 停止温度状態（Picker）
```

| 親項目（セクション） | 操作 | 子項目 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 自動ステータス更新（画面表示・機能制御） | 有効にする | 自動キャンセル、自動延長（配下すべて） | 🟢正常系：無効→有効に切替 | 自動キャンセル・自動延長の設定項目群が表示される |
| 自動ステータス更新 | 無効にする | 同上 | 🟢正常系：有効→無効に切替 | 自動キャンセル・自動延長と全子項目が非表示になり、非表示項目はデフォルト値に復元される |
| 自動キャンセル（画面表示・機能制御） | 有効にする | 時間（秒）、前通知ON/OFF | 🟢正常系：無効→有効に切替 | 自動キャンセル時間と前通知設定が表示される |
| 自動キャンセル前通知 | 有効にする | 前通知時間（秒） | 🟢正常系：無効→有効に切替 | 前通知時間の入力欄が表示される |
| 自動延長（画面表示・機能制御） | 有効にする | タイミング（分）、延長時間（分） | 🟢正常系：無効→有効に切替 | 延長タイミングと延長時間の入力欄が表示される |
| 終了前リマインダー（SE・通知） | 有効にする | 通知時間（秒）、繰り返し、リマインダー音 | 🟢正常系：無効→有効に切替 | 通知時間・繰り返し設定・音の選択が表示される |
| リマインダー繰り返し | 回数指定にする | リマインダー回数（回） | 🟢正常系：無限→回数指定に切替 | 回数入力欄が表示される |
| 解錠機能（デバイス・解施錠） | 解錠する | 解錠デバイス1/2 | 🟢正常系：「解錠する」に切替 | 解錠デバイスPickerが表示される |
| 解錠機能 | 解錠しない | 同上 | 🟢正常系：「解錠しない」に切替 | 解錠デバイスPickerが非表示になる |
| 常時接続（デバイス・解施錠） | 有効にする | 常時接続対象デバイス | 🟢正常系：無効→有効に切替 | 常時接続対象デバイスの選択が表示される |
| なりすまし防止（顔認証） | 有効にする | 防止モード、自動切替、防止期間 | 🟢正常系：無効→有効に切替 | 防止モード等の設定が表示される |
| 省エネモード（画面表示・機能制御） | カスタムにする | 4つの条件Picker | 🟢正常系：標準→カスタムに切替 | 開始/停止のバッテリー・温度Pickerが表示される |

### ルール⑫: テキスト入力の文字数バリデーション（初期設定画面）
