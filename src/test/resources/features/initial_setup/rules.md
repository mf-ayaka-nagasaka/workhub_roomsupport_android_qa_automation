## ルールの洗い出しと正常系・異常系の分類

### 機能名: 予約認証モードでの初期設定
**機能概要:** 管理者がタブレットの初回起動時に、認証方式の選択 → 設定方法の選択 → 利用タイプ／テンプレート（またはコピー元）の選択を行い、続く設定画面で各種設定を入力・保存して、予約認証モードでの初期設定を完了しホーム画面に到達する。

**ウィザードの全体構造（ステップの並び）:**
```
[1] 認証方法選択      … QR認証のみ / QR+顔認証
      └ QR+顔の場合 → 認証方法説明 → 顔認証有効化（申請→承認）
[2] 設定方法選択      … テンプレート / 既存設定をコピー（2択）
      ├ テンプレート → [3] 利用タイプ選択 → 確認ダイアログ（実行／キャンセル）
      └ コピー       → [3'] コピー元選択
[4] 設定画面（初期設定モード）… 各種設定の入力・保存（コピー設定もこの画面で指定）
[5] 初期設定完了 → ホーム画面
```

---

### ルール①: 管理者はQR認証のみ／QR+顔認証のいずれかを選択して初期設定を開始できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 認証方式選択後のページ遷移はViewModelのpage状態変化であり、実機描画なしでストリーム検証可能なため。

| 対象 | 組織の顔認証状態 | 認証方式 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 未有効化 | - | 🟢正常系：認証方法選択ステップを表示する | 「QR認証のみ」「QR+顔認証」の2つの選択肢が表示される |
| 管理者 | 未有効化 | QR認証のみ | 🟢正常系：QR認証のみを選択 | 設定方法選択ステップに進む |
| 管理者 | 未有効化 | QR+顔認証 | 🟢正常系：QR+顔認証を選択 | 認証方法説明ステップに進む（顔認証有効化フローが開始される） |
| 管理者 | 有効化済み | -（選択不要） | 🟢正常系：組織で顔認証が既に有効化されている状態で初期設定を開始 | 認証方法選択ステップはスキップされ、設定方法選択ステップから開始される |
| 管理者 | 未有効化 | -（選択前） | 🟡例外系：認証方式選択中にアプリを終了し再起動 | 認証方法選択ステップから再開される（進行状態: initializing） |

### ルール②: 顔認証を選択した管理者は、有効化の承認を得なければ設定方法選択に進めない
**推奨テスト階層:** Application Unitテスト (JVM)
**割り振り理由:** 顔認証アクティベーション申請→承認検知→ページ遷移の一連のユースケースフローを通しで検証するため。

| 対象 | 有効化の状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 説明ステップ | 🟢正常系：認証方法説明を確認して次へ進む | 有効化の申請が送信され、申請完了の表示に切り替わる |
| 管理者 | 申請送信済み・未承認 | 🟢正常系：申請完了の表示を確認する | 承認完了の連絡を待つ旨が表示され、設定方法選択には進めない |
| 管理者 | 申請送信済み・起動したまま承認 | 🟢正常系：アプリを起動したままバックエンドで承認される | 承認済みの表示に自動で切り替わり、「設定をはじめる」で設定方法選択ステップに進める |
| 管理者 | 申請送信済み | 🟢正常系：申請をキャンセルする | 申請が取り消され、認証方法選択ステップに戻る |
| 管理者 | 説明ステップ | 🟡例外系：認証方法説明ステップでアプリを終了し再起動 | 認証方法選択ステップに戻る（進行状態: initializingのまま） |
| 管理者 | 申請送信済み・未承認 | 🟡例外系：申請送信後にアプリを終了し再起動 | 認証方法選択ステップから再開され、「QR認証のみ」「QR+顔認証」の選択が再び求められる（申請を送っても進行状態は initializing のままのため、顔認証有効化ステップには復帰しない） |
| 管理者 | 申請送信済み・アプリ終了中に承認 | 🟡例外系：アプリを終了している間に承認され、その後再起動 | 組織の顔認証が有効化済みとして扱われるため、承認済みの表示は出ず、認証方法選択ステップを飛ばして設定方法選択ステップから開始される |

### ルール③: 管理者は設定方法（テンプレート／既存設定をコピー）を選んで設定の構成を開始できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 設定方法選択後のページ遷移はViewModelの状態変化であり、ストリーム検証で完結するため。

> **コピー元が0件のときの扱い:** 設定方法選択ステップでは既存設定の件数を判定しない。判定するには端末情報の取得が必要になり、テンプレートを選ぶ管理者にも待ち時間が生じてしまうため。「既存設定をコピー」は件数に関わらず常に選択でき、件数は遷移先のコピー元選択ステップで取得して、0件ならその旨を表示する。

| 対象 | コピー可能な既存設定 | 設定方法 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 件数を問わない | - | 🟢正常系：設定方法選択ステップを表示する | 「テンプレート」「既存設定をコピー」の2つの選択肢が表示され、既存設定の件数に関わらずいずれも選択できる |
| 管理者 | あり（1件以上） | テンプレート | 🟢正常系：テンプレートを選択 | 利用タイプ選択ステップに進む |
| 管理者 | あり（1件以上） | 既存設定をコピー | 🟢正常系：既存設定をコピーを選択 | コピー元選択ステップに進む |
| 管理者 | なし（0件） | 既存設定をコピー | 🟢正常系：既存設定が0件の状態でコピーを選ぶ | 「既存設定をコピー」は非活性にならず選択でき、コピー元選択ステップへ進む。進んだ先で取得した結果に応じて、一覧に表示できる設定がない旨が表示される |
| 管理者 | - | -（選択前） | 🟡例外系：設定方法選択中にアプリを終了し再起動 | 設定方法選択ステップから再開される（進行状態: selectSetting） |

### ルール④: テンプレートを選んだ管理者は、利用タイプを指定して設定を構成できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 利用タイプ選択後の確認ダイアログの表示と、実行／キャンセルによる分岐はViewModelの状態変化であり、ストリーム検証で完結するため。

**前提:** 設定方法選択で「テンプレート」を選んだ状態。選択肢は Standard / Enterprise / ThirdPlace / ビルテナント / カスタム の5種。

> **テンプレート一覧を経由しない理由:** 利用タイプはすべて会議室予約を前提とするため、利用タイプごとにテンプレートが1つに定まる。テンプレートを一覧から選ぶ画面は表示されず、利用タイプの選択がそのままテンプレートの選択となる。

| 対象 | 利用タイプ | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | - | 🟢正常系：利用タイプ選択ステップを表示する | Standard / Enterprise / ThirdPlace / ビルテナント / カスタム の5つの選択肢が表示される |
| 管理者 | 5種のいずれか | 🟢正常系：利用タイプを押下する | 選んだ利用タイプで設定を構成してよいかを確認するダイアログが表示され、「実行」「キャンセル」を選べる |
| 管理者 | Standard | 🟢正常系：確認ダイアログで「実行」を選択 | テンプレート一覧を経由せず、設定画面に到達する |
| 管理者 | Enterprise | 🟢正常系：確認ダイアログで「実行」を選択 | テンプレート一覧を経由せず、設定画面に到達する |
| 管理者 | ThirdPlace | 🟢正常系：確認ダイアログで「実行」を選択 | テンプレート一覧を経由せず、設定画面に到達する |
| 管理者 | ビルテナント | 🟢正常系：確認ダイアログで「実行」を選択 | テンプレート一覧を経由せず、設定画面に到達する |
| 管理者 | カスタム | 🟢正常系：確認ダイアログで「実行」を選択 | テンプレート一覧を経由せず、設定画面に到達する |
| 管理者 | 5種のいずれか | 🟢正常系：確認ダイアログで「キャンセル」を選択 | ダイアログが閉じて利用タイプ選択ステップに留まり、設定画面には遷移しない |
| 管理者 | -（選択前） | 🟡例外系：利用タイプ選択中にアプリを終了し再起動 | 認証方法選択ステップに戻る（進行状態: initializing のまま） |

### ルール⑤: 選択した利用タイプに対応するテンプレートの設定値が設定画面に適用される
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 利用タイプに応じた設定値の適用はViewModelのUiState変化であり、ストリーム検証で完結するため。

| 対象 | 利用タイプ | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | Standard | 🟢正常系：Standardで設定の構成を実行 | Standardのテンプレートの設定値が適用された状態で設定画面に到達する |
| 管理者 | Enterprise | 🟢正常系：Enterpriseで設定の構成を実行 | Enterpriseのテンプレートの設定値が適用された状態で設定画面に到達する |
| 管理者 | ThirdPlace | 🟢正常系：ThirdPlaceで設定の構成を実行 | ThirdPlaceのテンプレートの設定値が適用された状態で設定画面に到達する |
| 管理者 | ビルテナント | 🟢正常系：ビルテナントで設定の構成を実行 | ビルテナントのテンプレートの設定値が適用された状態で設定画面に到達する |
| 管理者 | カスタム | 🟢正常系：カスタムで設定の構成を実行 | テンプレートの設定値は適用されず、各項目がデフォルト値の状態で設定画面に到達する |

### ルール⑥: コピーを選んだ管理者は、予約認証モードの既存設定を指定して設定を構成できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** コピー元一覧の表示・検索・絞り込み・選択・削除はすべてViewModelの状態変化であり、ストリーム検証で完結するため。

**前提:** コピー元一覧には、コピー設定が登録済みかつ**予約認証モードで設定された端末のみ**が表示される。常時認証モードで設定された端末は一覧に表示されない。

| 対象 | 既存設定 | 操作 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | あり（1件以上） | コピー元を選択 | 🟢正常系：コピー元の既存設定を指定 | コピー元の設定値が適用され、設定画面に到達する |
| 管理者 | 予約認証と常時認証が混在 | 一覧を表示 | 🟢正常系：常時認証モードの端末が混在する状態で一覧を表示 | 予約認証モードの端末のみが表示され、常時認証モードの端末は表示されない |
| 管理者 | 0件（未登録） | 一覧を表示 | 🟢正常系：コピー設定が1件も登録されていない状態で一覧を表示 | 一覧に表示できる設定がない旨が表示され、設定方法選択ステップには戻らない |
| 管理者 | 常時認証モードのみ | 一覧を表示 | 🟢正常系：予約認証モードで設定された端末が1件も存在しない | 一覧に表示できる設定がない旨が表示される |
| 管理者 | あり（複数件） | 一覧を表示 | 🟢正常系：識別名称が異なる既存設定が複数ある状態で一覧を表示 | 識別名称の昇順で並んで表示される |
| 管理者 | あり（複数件） | 識別名称で検索 | 🟢正常系：識別名称のキーワードで一覧を検索 | 検索条件に一致するコピー設定のみ表示される |
| 管理者 | あり（複数件） | 大文字小文字が異なるキーワードで検索 | 🔴異常系：識別名称が "ABC会議室" の設定に対して "abc会議室" で検索 | 大文字小文字は区別されるため一致せず、一覧に表示できる設定がない旨が表示される |
| 管理者 | あり（複数件） | 利用タイプで絞り込み | 🟢正常系：利用タイプ（Standard / Enterprise / ThirdPlace / ビルテナント / カスタム）で絞り込み | 指定した利用タイプのコピー設定のみ表示される |
| 管理者 | あり（複数件） | 認証モードで絞り込み | 🟢正常系：認証モード（QRコードのみ / 顔+QRコード）で絞り込み | 指定した認証モードのコピー設定のみ表示される |
| 管理者 | あり（複数件） | 複数条件で絞り込み | 🟢正常系：検索キーワード・利用タイプ・認証モードを同時に適用 | すべての条件に一致するコピー設定のみ表示される |
| 管理者 | あり（複数件） | 絞り込みを解除 | 🟢正常系：適用した絞り込み条件を解除 | 絞り込み前の一覧に戻る |
| 管理者 | あり（複数件） | 該当なしの条件で絞り込み | 🔴異常系：どの設定にも一致しない条件で検索・絞り込み | 一覧に表示できる設定がない旨が表示される |
| 管理者 | あり（2件以上） | コピー設定を削除 | 🟢正常系：削除を選び、確認ダイアログで「削除」を選択 | 対象の既存設定が一覧から削除され、残りの設定が表示されたままになる |
| 管理者 | あり（2件以上） | 削除をキャンセル | 🟢正常系：削除を選び、確認ダイアログで「キャンセル」を選択 | 削除されず、一覧の内容が変わらない |
| 管理者 | あり（1件のみ） | コピー設定を削除 | 🟢正常系：最後の1件を削除する | 一覧が0件になり、コピー元選択ステップに留まったまま、一覧に表示できる設定がない旨が表示される |
| 管理者 | - | 一覧を取得 | 🟡例外系：コピー元一覧の取得に失敗する | エラーページが表示される |
| 管理者 | あり | コピー元選択中に中断 | 🟡例外系：コピー元選択中にアプリを終了し再起動 | 認証方法選択ステップに戻る（進行状態: initializing のまま） |

### ルール⑦: 管理者はウィザードの各ステップから前のステップに戻れる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 戻る操作によるページ状態の巻き戻しはViewModelのpage状態変化であり、ストリーム検証で完結するため。

| 対象 | 現在のステップ | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 認証方法選択 | 🟢正常系：初期設定が未完了の状態で認証方法選択ステップを表示する | 戻るボタンは表示されない（最初のステップのため） |
| 管理者 | 認証方法説明 | 🟢正常系：戻るボタンを押す | 認証方法選択ステップに戻る |
| 管理者 | 顔認証有効化 | 🟢正常系：戻るボタンを押す | 認証方法選択ステップに戻る |
| 管理者 | 設定方法選択 | 🟢正常系：戻るボタンを押す | 認証方法選択ステップに戻る |
| 管理者 | 利用タイプ選択 | 🟢正常系：戻るボタンを押す | 設定方法選択ステップに戻る |
| 管理者 | コピー元選択 | 🟢正常系：戻るボタンを押す | 設定方法選択ステップに戻る |
| 管理者 | 認証方法選択まで戻った状態 | 🟢正常系：戻った後に別の認証方式を選び直す | 選び直した認証方式に応じたステップに進む |

### ルール⑧: 予約認証モードのスペース選択には予約設定のあるスペースのみ表示される
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** スペース一覧のフィルタリング表示はViewModelの状態変化であり、ストリーム検証で完結するため。

| 対象 | スペースの状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 予約設定あり（通常予約） | 🟢正常系：通常予約の設定があるスペース | スペース選択項目に表示され、選択できる |
| 管理者 | 予約設定あり（サードプレイス） | 🟢正常系：サードプレイスの設定があるスペース | スペース選択項目に表示され、選択できる |
| 管理者 | 予約設定なし | 🟢正常系：予約設定のないスペース | スペース選択項目に表示されず、選択できない |
| 管理者 | 予約設定ありが0件 | 🔴異常系：予約設定のあるスペースが1件も存在しない | 選択肢が表示されず、スペースを選択できない |
| 管理者 | 選択して保存 | 🟢正常系：表示されたスペースを選択して保存 | 設定が保存され、初期設定完了が表示される |

### ルール⑨: 初期設定の保存には必須項目の入力と予約認証方法の選択が必要
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 各フィールドのバリデーション状態とエラー表示はViewModelのUiState変化であり、実機描画なしで検証可能なため。

| 対象 | バリデーション項目 | 入力状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 全項目 | すべて入力済み | 🟢正常系：必須項目をすべて入力して保存 | 保存処理が実行される |
| 管理者 | 予約認証方法 | 未選択 | 🔴異常系：予約認証方法を選択せずに保存 | エラー「予約認証の認証方法を選択してください」が表示され、保存されない |

### ルール⑬: 初期設定の保存が完了すると初期設定完了が表示されホームに到達できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 保存完了→完了画面表示→ホームへの遷移要求までがViewModelのUiState/Effect変化であり、ストリーム検証で完結するため。

**前提:** 設定コピーは、設定画面の「コピー設定」セクションで指定し、**端末設定の保存と同時に反映される**（保存後に登録有無を選ぶ確認画面は存在しない）。

| 対象 | コピー設定 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 有効 | 🟢正常系：コピー設定を有効にし、識別名称を入力して保存する | 設定が保存されるとともに設定コピーが登録され、初期設定完了が表示される |
| 管理者 | 無効 | 🟢正常系：コピー設定を無効のまま保存する | 設定コピーは登録されず、初期設定完了が表示される |
| 管理者 | 有効 | 🟢正常系：コピー設定を有効にしたまま端末設定を保存し直す | 確認を挟まずに、その端末の既存のコピーデータが最新の設定内容で上書きされる |
| 管理者 | 有効 | 🟢正常系：コピー設定を有効にして保存した後、設定画面の「既存設定をコピー」からコピー元一覧を表示する | 登録した識別名称がコピー元の選択肢として表示される |
| 管理者 | - | 🟢正常系：初期設定完了の表示から次へ進む | 設定の再読み込みを経てホーム画面に到達する |

### ルール⑭: 初期設定が完了した端末では、再起動してもウィザードが表示されない
**推奨テスト階層:** Application Unitテスト (JVM)
**割り振り理由:** 起動時の設定読み込み→完了判定→遷移先決定という一連のユースケースフローを通しで検証するため。

| 対象 | 進行状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 完了済み | 🟢正常系：初期設定を完了した端末を再起動する | 初期設定ウィザードは表示されず、ホーム画面に到達する |
| 管理者 | 未完了 | 🟢正常系：初期設定が未完了の端末を再起動する | 初期設定ウィザードが、中断時点の進行状態に応じたステップで表示される |
