機能: 設定値の読み込み
  アプリ起動時に、権限確認 → 保存済みログイン状態の確認 → 認証情報の更新 を行い、すべて成功した
  場合のみ ①組織情報 → ②端末設定（タブレット1台分の設定）の順でサーバから設定値を自動取得し、
  取得結果に応じて起動準備・初期設定・設置手続きのいずれかへ利用者を振り分ける。
  ※いずれかの工程で止まった場合、後続の工程には進まない。①で失敗した場合も②に進まない。

  背景:
    前提 タブレット "会議室A設置タブレット" にRoomSupportアプリがインストールされている
    かつ 管理者 "山田" は [テスト用組織] の管理者である
