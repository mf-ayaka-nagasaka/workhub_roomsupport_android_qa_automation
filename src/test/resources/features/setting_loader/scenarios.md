機能: 設定値の読み込み
  ログイン成功後に、①組織情報 → ②端末設定（タブレット1台分の設定）の順でサーバから設定値を
  自動取得し、取得結果に応じて起動準備・初期設定・設置手続きのいずれかへ利用者を振り分ける。
  ※①で失敗した場合は②に進まない。

  背景:
    前提 タブレット "会議室A設置タブレット" にRoomSupportアプリがインストールされている
    かつ 管理者 "山田" は [テスト用組織] にログイン済みである
