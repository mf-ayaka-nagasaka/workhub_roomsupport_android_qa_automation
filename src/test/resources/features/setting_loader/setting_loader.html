setting_loader

アプリを起動してから、タブレットが「使える状態」に着くまでに裏で何が順番に起きるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

ルール① 権限が揃うまで先へ進まない

権限が足りない → 案内が出続け、先へ進まない
権限を許可する → 案内が閉じて続きが始まる

ルール② ログインの記録で行き先が決まる

記録あり → 本人確認へ／記録なし・判定できない → ログイン画面へ

ルール③ 本人確認は3回までやり直す

1回目・やり直しで成功 → 読み込みが始まる
30秒で終わらない → 失敗として扱われ、やり直しへ

ルール④ 3回ダメだったときの行き先

本人確認に必要な情報がない → 案内なしでログイン画面へ
本人確認を断られた＋控えなし → 言葉が出てからログイン画面へ
控えあり → 失敗の種類を問わず、控えを使って使える状態へ
つながらない＋控えなし → 接続待ちになる

ルール⑤ 接続待ちからの進み方

接続待ちの表示と、ログイン画面へ行く手段がある
つながれば本人確認をやり直して読み込みへ／選べばログイン画面へ

ルール⑥ 設定が読み込まれて使える状態になる

設定があり初期設定も済み → 読み込んで使える状態へ
読み込み中は何も操作できない
途中で終了して再起動 → どこから再開するか

ルール⑦ 初期設定が終わっていなければ初期設定へ

終わっていない → 初期設定へ／終わっている → 使える状態へ

ルール⑧ 設定が無ければ設置方法を選ぶ

設定が無い → 設置方法の選択が出る
再設置 → 再設置へ／新規設置 → 設定を作って初期設定へ
新しい設定を作れない → ログイン画面へ戻る
識別情報が読めない → 代わりの情報で探すため選択が出る／読めたら読み込みをやり直す
読めないまま選ぶと、代わりの情報がこの端末の識別情報として確定する
再設置から戻る → 設置方法の選択に戻る

ルール⑨ 取れないときは取り直す

途中で取れるようになれば、そのまま使える状態へ
3回取り直してもダメ → ログイン画面へ戻る

ルール⑩ 組織の情報が取れないときは取り直さない

組織の情報が取れない → 取り直さずログイン画面へ
1回だけの失敗でも取り直さない（⑤との違い）

通し（実機で最後まで）

権限が揃いログイン済み：起動するだけで読み込みまで
設置済みの端末：起動するだけで使える状態まで
未設置の端末：新規設置を選んで初期設定まで

エラーの言葉で、止まった場所がわかる

画面に出る言葉止まった場所
token失効により自動ログインに失敗しました③ 本人確認を3回やり直してもダメだったとき（断られた場合のみ）
組織情報の取得に失敗しました④ 組織の情報を取る（取り直しなし・すぐログイン画面へ）
端末情報の取得に失敗しました…(1)⑤ 設定が取れない・中身がおかしいとき ／ ⑧ 端末の情報が整わないとき（いずれも3回取り直した後）
端末情報の取得に失敗しました…(2)⑧ そのほかの失敗（3回取り直した後）
初期設定に失敗しました⑥ 新しい設定を作れないとき
