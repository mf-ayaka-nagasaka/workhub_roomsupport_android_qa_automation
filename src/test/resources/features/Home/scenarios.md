# language: ja
機能: 部屋の予約状況をホーム画面に表示できる
  会議室のドア前に常設されたタブレットで、部屋がいま「空室／入室待ち／利用中」のどれなのかを背景色・中央サークル・主ボタンで示し、残り時間を1秒ごとに更新する。予約の作成・削除は他の経路で行われても表示へ反映される

  背景:
    前提 会議室タブレットは予約認証モードで設定されており、起動準備を終えてホーム画面を表示している

  # ────────────────────────────────────────

  シナリオアウトライン: 予約の状況に応じて空室・入室待ち・利用中の表示が切り替わる
    前提 事前入室可能時間が10分に設定されている
    かつ 設置空間の予約が <予約の状況> である
    もし 現在時刻が <現在時刻> になる
    ならば ホームは <状態> として表示される
    かつ 主ボタンのラベルは <ラベル> になる

    例:
      | 予約の状況                         | 現在時刻 | 状態                     | ラベル     |
      | 1件も無い                          | 9:00     | 空室（白基調）           | 今すぐ入室 |
