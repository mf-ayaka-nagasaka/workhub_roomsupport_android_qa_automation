# ログイン・組織選択 — ルール・実例・Gherkinシナリオ

## パート1: ルールの洗い出しと正常系・異常系の分類

### 機能名: ログイン・組織選択
**機能概要:** メールアドレスとパスワードでWorkhubアカウントにログインし、複数組織に所属する場合は利用組織を選択してログインを完了する。

---

### ルール①: 有効な認証情報を持つユーザーはWorkhubにログインできる
**推奨テスト階層:** Application Unitテスト (JVM)
**割り振り理由:** BKP認証→組織数判定→遷移先分岐の一連のユースケースフローを通しで検証するため。

**補足:**
- フォーム情報保持はしない。ログイン後の認証情報は保持する。

| 対象 | 組織数 | ネットワーク | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 正規ユーザー | 1組織 | 接続済み | 🟢正常系：正しいメール・パスワードで単一組織アカウント | ログイン成功＆設定読み込み画面遷移 |
| 正規ユーザー | 2組織以上 | 接続済み | 🟢正常系：正しいメール・パスワードで複数組織アカウント | 組織選択画面表示 |
| ユーザー | - | 接続済み | 🔴異常系：未登録のメールアドレスでログイン試行 | エラーメッセージ表示 |
| ユーザー | - | 接続済み | 🔴異常系：誤ったパスワードでログイン試行 | エラーメッセージ表示 |
| ユーザー | - | 接続済み | 🔴異常系：メールアドレスorパスワードが未入力の場合 | ボタンが非活性になっている |
| ユーザー | - | 接続済み | 🔴異常系：メールアドレスの形式が不正の場合 | エラーメッセージ表示 |
| ユーザー | - | 未接続 | 🔴異常系：オフライン状態でログイン試行 | エラーメッセージ表示 |
| ユーザー | - | 途中切断 | 🔴異常系：認証途中で中断した場合 | エラーメッセージ表示 |
| ユーザー | - | 接続済み | 🔴異常系：誤ったパスワードをn回入力する | アカウントロックがされる |
| ユーザー | - | 接続済み | 🔴異常系：アカウントロック中にログインを試行した場合 | エラーメッセージ表示 |
| ユーザー | 0組織（非対応） | 接続済み | 🔴異常系：退職済みのアカウント | エラーメッセージ表示 |

---

### ルール②: 複数組織ユーザーは組織を選択してログインを完了できる
**推奨テスト階層:** Application Unitテスト (JVM)
**割り振り理由:** 組織選択→WorkHubログイン→認証完了の一連のユースケースフローを通しで検証するため。

**補足:**
- 組織選択後のステップを画面に表示（ex: 組織にログイン中、workhubにログイン中、Firebase(?)にログイン中など）
- 複数とはどれくらい？
  - スクロールは必要なのかも含めて。
  - 画面内に収まりきらない組織名

| 対象 | 選択状態 | API状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 複数組織ユーザー | 1件選択済み | 正常 | 🟢正常系：組織を選択して確定 | ログイン成功＆設定読み込み画面遷移 |
| 複数組織ユーザー | 未選択 | 正常 | 🟢正常系：組織を選択していない場合 | ボタンが非活性になっている |
| 複数組織ユーザー | 未選択/1件選択済み | 正常 | 🟢正常系：ログアウトすることができる | ダイアログで確認後にログイン画面に遷移 |
| 複数組織ユーザー | 1件選択済み | NW切断 | 🔴異常系：組織選択後の処理中にネットワーク切断 | エラーメッセージ表示 |
| 複数組織ユーザー | 1件選択済み | 切断 | 🔴異常系：組織選択画面でタスクキル→再起動 | 組織選択画面表示 |
| 複数組織ユーザー | 1件選択済み | 切断 | 🔴異常系：組織選択後（組織選択の処理完了）＆認証中にタスクキル→再起動 | ログイン後の画面表示 |
| 複数組織ユーザー | 1件選択済み | 切断 | 🔴異常系：組織選択後（組織選択の処理未完了）＆認証中にタスクキル→再起動 | 組織選択画面表示 |
| 複数組織ユーザー | 1件選択済み | 正常 | 🔴異常系：複数組織すべて退職済みの状態で組織を選択した場合 | エラーメッセージ表示 |

---

### 疑問点・未確認事項（赤カード）
- [ ] 各エラーケースの**具体的なエラーメッセージ文言・エラーコード**が未確定。仕様書での定義確認が必要。
- [ ] **アカウントロックの閾値**（n回）が未定義。具体的な回数と、ロック解除の条件（時間経過？管理者操作？）も未確認。
- [ ] **アカウントロック中のログイン試行**時の具体的なエラーメッセージが未確認。ロックの残り時間表示等の仕様も未定義。
- [ ] **認証途中のネットワーク切断**時の具体的なエラーメッセージ・リトライ挙動が未確認。
- [ ] **メールアドレス形式バリデーション**のルール（クライアント側チェックか、サーバー側のみか）が未確認。
- [ ] 組織選択画面の**ログアウト操作**のUIフロー（ボタン配置、確認ダイアログの文言）が未確認。
- [ ] **組織選択後のステップ表示**（「組織にログイン中」「workhubにログイン中」等のプログレス表示）の仕様が未確認。
- [ ] 組織選択画面に表示される**組織数の上限**、および**スクロール挙動**が未確認。
- [ ] **画面内に収まりきらない組織名**の表示仕様（省略表示、折り返し等）が未確認。
- [ ] **組織選択後（処理完了/未完了）のタスクキル→再起動**における「処理完了」の判定基準が未確認。
