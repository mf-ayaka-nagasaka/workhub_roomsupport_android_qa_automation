# language: ja
機能: ログイン・組織選択
  Workhubアカウントのメールアドレスとパスワードでタブレット端末にログインし、
  複数組織に所属する場合は利用する組織を選択してログインを完了する。
  エラーが発生した際は、画面にエラーメッセージを表示する

  背景:
    前提 タブレットにRoomSupportアプリがインストールされている
