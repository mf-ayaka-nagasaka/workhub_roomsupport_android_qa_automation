予約認証設定の変更

管理者メニューから設定の画面を開いて、各項目を入れ替えて保存し、元の画面に戻るまでの流れを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝うまくいかないときの確認。

ルール① 変えて保存する

項目を変えて保存できる
何も変えずに保存しても保存される
保存中は画面を操作できない
続けて押しても保存は1回だけ
保存に失敗する → その場に留まる

ルール② 保存したあとの効き方

変えた内容がホーム画面などに出る
どこから開いたかで戻り先が変わる

ルール③ 開いたときの見え方

今までの値が全部入って表示される
親がONなら、ぶら下がる項目も開いて出る
今のモードに関係ない項目は出ない
顔が使えない組織 → 顔のまとまりが出ない
顔が使えない組織 → 顔の認証を選べない
名前か空間が空だと、やめる操作が出ない

ルール④ 使う空間を選ぶ

予約の設定がある空間だけ選べる
選べる空間が0件 → 空間を選べない
空間の一覧が出てこない → 選べない

ルール⑤ 顔がないとONにできない機能

顔が入っていれば予約作成をONにできる
顔が使えない組織 → そもそも選べない
QRだけでONにする → その場で知らせが出る
直さずに保存 → 保存できない
その場の案内から顔を足す → 直って保存できる

ルール⑥ 顔を外したときの巻き添え

顔を外そうとすると、消える項目を教えてくれる
確認して外す → 関係する項目もまとめてOFF
やめる → 顔もほかの項目もそのまま
巻き添えが無いときは確認なしで外せる

ルール⑦ 入力の不備の知らせ方

不備の数で知らせ方が変わる（1件／3件／4件）
どのまとまりに不備があるか数で分かる
直してもう一度保存 → 保存できる
隠した項目のうち、おかしな値は既定の値に戻して保存される

ルール⑧ やめる

変えたあとにやめる → 確認なしで元に戻る
何も変えずにやめる → 元の画面に戻る
やめたあとに開き直す → 前の値のまま

ルール⑨ コピーとして残す

名前を付けて残す → 元の画面に戻る
残さないを選ぶ → 元の画面に戻る
名前が空 → 残す操作ができない
残すのに失敗 → 設定の保存自体は済んでいる

ルール⑩ つなぎっぱなしのおすすめ

すすめに乗る → つなぎっぱなしが有効になって保存
そのまま保存 → 無効のまま保存
条件を満たさないとおすすめは出ない

ルール⑪ ほかの設定を持ってくる

ひな形／別の端末の設定で中身を入れ替える
確認でやめる → 今の入力はそのまま
入れ替えても名前と空間はそのまま
元にできる設定が0件 → 選べない

ルール⑫ 空間を変えたときの巻き添え

空間を変える → 開ける機器の選択が外れる
つなぎっぱなしの対象からも外れる
同じ空間を選び直しても外れない
変えたあとは、その空間の機器だけ出る

ルール⑬ 各項目を入れ替える

親をONにすると、ぶら下がる項目が出る
親をOFFにすると隠れる
隠れた項目に入れた値はそのまま残る
使い方のタイプで2台目の機器が出る／出ない
単独の切り替えを変えて保存できる
QRだけ／顔だけ／両方 に変えて保存できる
認証のしかたを全部外す → 保存できない
できることを1つずつ切り替えて保存できる
機器・音・時間帯を選んで保存できる
同じ機器を2つ選ぶと1台にまとまる
開けると決めたのに機器が空 → 保存できない

ルール⑭ 数と文字数の決まり

いちばん小さい値ちょうど → 保存できる
0・マイナス・空 → 項目ごとの言葉で止まる
決められた範囲の端の値 → 保存できる
範囲から外れた値 → 保存できない
文字数が上限以内 → 保存できる
文字数が上限を超える → 保存できない
合いことばに触らなければ変わらない
合いことばを入れ替えて保存できる
合いことばと確認用が違う・空 → 保存できない
名前を空にする → 保存できない

ルール⑮ 途中で止めたとき

保存せずに止める → 入れかけは残らない
残すかの確認で止める → 保存した分は消えない

通し（実機で最後まで）

変えて保存 → ホーム画面に効いている
顔を足して保存 → 認証の画面で顔が使える
変えて保存 → 名前を付けてコピーを残す
