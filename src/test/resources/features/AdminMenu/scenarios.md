# language: ja
機能: 管理メニュー
  タブレット設置管理者が、特定のジェスチャー操作から起動する隠し管理メニューを、
  パスワードまたは顔認証で保護した上で開き、端末情報確認・設定更新・
  顔認証関連管理・ログアウトを行う。

  背景:
    前提 タブレットにRoomSupportアプリがインストールされている
    かつ ホーム画面が表示されている
