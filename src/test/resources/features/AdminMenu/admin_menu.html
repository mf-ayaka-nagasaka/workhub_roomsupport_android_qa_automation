管理メニュー

ロゴを決まった操作でタップしてから、機器を管理するメニューにたどり着くまでに何が起きるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

ルール① 決まった操作でメニューを開く

ホーム画面で決まった操作をする → 確認画面が開く
別の画面（予約認証のカメラ確認画面）で同じ操作をしても反応しない
操作の一部だけ行う → 反応しない
操作の間隔が空きすぎる → 反応しない
設定などの画面から戻る → 確かめ直さずメインメニューへ

ルール② 確認方法が自動で決まる

顔で確かめる設定オン → 顔の確認画面（決められた動作をしてもらう方式）
顔で確かめる設定がオフ → パスワードの確認画面

ルール③ 顔で確認するときは管理する権限がある人だけ入れる

権限がある人が顔で確かめられる → メインメニューへ
本人だと確かめられても権限がない → 入れずホーム画面へ
決められた動作の案内（絵と言葉）が出る
決められた動作をしない・違う動作をする → 最初の案内からやり直し
なりすましを見つける → 理由に合った案内が出て、確認は続く
顔が端末に登録されていない → 「顔情報が未登録です」が出て、確認は続く
端末の顔情報と合わない → 何も出ないまま、確認は続く
顔が画面の外に出る → 案内が新しくならない
立ち位置・顔の向き・明るさが合わない → 理由に合った案内が出る
パスワードでの確認に切り替える
顔の確認をやめる（「キャンセル」／枠の外を押す） → 元の画面に戻る

ルール④ 正しいパスワードで開ける

決めたパスワードを入れる → メインメニューへ
パスワードを決めていない機種は、あらかじめ決まっている値で開ける
違うパスワードを入れる → 開かずやり直せる
パスワードの確認をやめる → 元の画面に戻る

ルール⑤ メニューの並びが設定で変わる

顔で確かめる設定オン → 顔に関する項目も並ぶ
顔で確かめる設定オフ → 代わりに「顔認証アクティベーション申請」だけ並ぶ
開いている間に設定がオフになった状態で顔に関する項目を選ぶ → 実行できず、メニューが今の状態に合わせて並び直す

ルール⑥ メニューから各機能を開く

「タブレット情報」を選ぶ → 13の項目が見られる
解錠のテストボタン → 設定と解錠機器のつながり方で出かたが変わる
通知のテストボタン → いつでも出る
「アクセスコントロールの確認」を選ぶ → 最終取得日時と一覧が見られる
突き合わせ先（解錠機器・人の情報）が無い行 → 一覧に出ない
0件／100件超 → それぞれの知らせが出る
絞り込みに文字を入れる → 当てはまる行だけ残る
「基本設定の更新」を選ぶ → 設定の画面へ
「顔情報登録」を選ぶ → 社員番号を入れる画面へ
「顔情報の再取得」を選ぶ → その場で取り直される
「顔認識機能のデバッグ」を選ぶ → 確認用の画面へ
「顔認証アクティベーション申請」を選ぶ → 申請が送られる

ルール⑦⑧ 閉じる・ログアウトする

確認画面でやめる → 元の画面に戻り、印も消える
メインメニューを閉じる → 元の画面に戻り、印も消える
ログアウトを選ぶ → ログイン画面に戻る

通し（実機で最後まで）

パスワードで開いて設定を変えるまで
顔で開いてログアウトするまで

エラーの言葉で、止まった場所がわかる

画面に出る言葉止まった場所
管理メニューを開く権限がありません④ 顔で本人確認（本人だが権限がないとき）
パスワードに誤りがあります③ パスワードを確認
顔認証の利用が制限されています。利用する場合はBitkeyにお問い合わせください。⑤ 選んだ項目を実行（顔に関する項目を選んだが設定がオフのとき）
