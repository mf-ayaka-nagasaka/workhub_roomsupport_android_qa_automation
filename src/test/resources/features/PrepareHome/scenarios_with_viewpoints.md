# language: ja
機能: 起動時に予約データを準備してホームを表示できる
  設定の読み込みを終えて起動準備画面に到達した後、進行中であることを示しながら設定の不備を確認し、予約データを含む各種データの初回到着を待機したうえでホーム画面へ自動遷移する

  背景:
    前提 端末の登録と初期設定が完了しており、設定の読み込みを終えて起動準備画面に到達している
