起動時に予約データを準備してホームを表示できる

設定の読み込みを終えて起動準備画面に着いたあと、ホーム画面が出るまでに裏で何が順番に起きるかを1枚にしたもの。端末の登録と初期設定の確認は、ひとつ前の設定読み込み画面の担当。利用時間外の表示・顔情報の同期・オフライン時の動きも、それぞれ別のチケットの担当なのでここには出てきません。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝進めない・止まる確認。

ルール① 準備中は「やっています」と示し、操作させない

起動準備画面に着くと「設定を反映しています」が出る
準備中は表示が続き、押せるものは出ない
準備が終わると表示が消える

ルール② 名前・設置場所に不備があると設定画面へ戻される

名前と設置場所がどちらも設定済み → 準備が続く
タブレット名が未設定 → 設定画面へ
設置場所が未設定 → 設定画面へ

ルール③ 準備全体が60秒を超えても止まらない

準備が60秒を超えた → それでも中断せずホーム画面へ

ルール④ 予約データの到着を待ってからホーム画面へ進む

予約データが10秒以内に届く → 反映された状態でホーム画面へ
予約データが10秒待っても届かない → そのままホーム画面へ進み、届き次第自動で反映

ルール⑤ 予約データの状態でホーム画面の見た目が決まる

予約がない → 空室状態で表示
予約はあるがまだ入室していない → 待機中状態で表示
入室済みの予約がある → 使用中状態で表示
予約はあるが入室可能時間の閾値に未到達 → 空室状態で表示
入室可能時間の閾値に到達した直後（境界値） → 待機中状態で表示

通し（実機で最後まで）

起動準備から予約データを反映したホーム画面表示までが正常に完了する
