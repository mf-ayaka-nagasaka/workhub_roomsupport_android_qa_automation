起動時に予約データを準備してホームを表示できる

設定の読み込みを終えて起動準備画面に着いたあと、ホーム画面が出るまでに裏で何が順番に起きるかを1枚にしたもの。端末の登録と初期設定の確認は、ひとつ前の設定読み込み画面の担当。利用時間外の表示・ホーム画面の見た目（空室／待機中／使用中）・顔情報の同期・オフライン時の動きも、それぞれ別のチケットの担当なのでここには出てきません。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝進めない・止まる確認。

ルール① 準備中は「やっています」と示し、操作させない

起動準備画面に着くと「設定を反映しています」が出る
準備中は表示が続き、押せるものは出ない
準備が終わると表示が消える

ルール② 名前・設置場所に不備があると設定画面へ戻される

名前と設置場所がどちらも設定済み → 準備が続く
タブレット名が未設定 → 設定画面へ
設置場所が未設定 → 設定画面へ

ルール③ 顔情報以外の準備がすべて揃うまでホーム画面へ進まない

スペースデータ・解錠デバイスの接続確認・予約データがすべて揃う → ホーム画面へ
解錠デバイスの接続確認が終わらない → ホーム画面へ進まず待ち続ける
予約データが揃わない → ホーム画面へ進まず待ち続ける
顔情報の修復だけ終わっていない → 待たずにホーム画面へ
揃うまでに60秒以上かかる → 打ち切られず、揃った時点でホーム画面へ

ルール④ 予約データは4種すべてを受け取れば「揃った」

予約認証モードで準備を始める → 予約一覧・空間ステータス・予約設定・利用不可時間の取得が始まる
4種すべてを受け取る → 揃ったものとして扱われる
予約が0件・利用不可時間の設定もない（中身が空） → それでも揃ったものとして扱われる
4種のうち一部しか受け取れない → 揃っていないものとして扱われ、待ちになる

ルール⑤ 揃わない間は理由と再試行の秒数を出し、30秒ごとにやり直す

30秒たっても揃わない → 待っている理由（未完了の処理）と次の再試行までの秒数が出る
再試行でやり直すのは未完了の処理だけ（終わった処理はやり直さない）
再試行10回目まで → ログアウトの導線は出ない（エラーも出ない）
再試行が10回を超える → ログアウトの導線が出る（待っている表示は続く）
待っている間に揃う → 待っている表示が消え、ホーム画面へ
ログアウトの導線を選ぶ → ログインが求められる

通し（実機で最後まで）
