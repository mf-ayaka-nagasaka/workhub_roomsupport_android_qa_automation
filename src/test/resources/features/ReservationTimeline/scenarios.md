# language: ja
機能: 当日の予約タイムラインを表示できる
  ホーム画面の下部に当日0時から24時までのタイムラインを表示し、設置空間の予約を時間帯のバーとして並べる。現在時刻の位置が分かるよう一定間隔で自動スクロールし、予約バーを押すと公開範囲に応じた詳細を確認できる

  背景:
    前提 会議室タブレットは予約認証モードで設定されており、ホーム画面を表示している
    かつ 設置空間の予約が同期されている

  # ※ 部屋の状態の判定は⑦「部屋の予約状況をホーム画面に表示できる」、削除の可否判定と実行は㉔「予約をキャンセル・削除できる」の責務（台帳 #24 #25）
  # ※ 背景色・バーの濃淡・現在時刻バーの色は検証対象外（⑦の方針に合わせる）
