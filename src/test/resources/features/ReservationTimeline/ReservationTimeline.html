当日の予約タイムラインを表示できる

会議室の前のタブレットが、ホーム画面の下に当日0時から24時までのタイムラインを描き、予約を押すと中身を見せるまでを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝出ない・止まるときの確認。

ルール① どの予約が帯になるか

当日の予約 → その時間の位置に帯が出る
前の日から続く予約 → 0時の手前から出る
次の日まで続く予約 → 右のはしの先まで出る
前の日から次の日まで続く → まる1日ぶん出る
前の日だけ・次の日だけの予約 → 出ない
遅れて入っても、帯の始まりは変わらない
早く出ていくと、帯の終わりがそこまで縮む
当日の予約が無い → 目盛りと今の時刻だけ

ルール② 目盛り・今の時刻・日付

0から23が並び、右のはしにもう一つ0が出る
今の時刻のところに線が出る
その日の日付と曜日が出る
0時をまたぐと、日付と帯が新しい日のものに変わる

ルール③ 帯の中の時刻

30分の予約 → 始まりと終わりの時刻が出る
25分30秒ちょうど → 時刻が出る
25分 → 帯は出るが時刻は出ない
日をまたぐ予約 → 日付つきの時刻が出る

ルール④ 今の時刻へ寄せる動き

10秒たつと、1時間前が左のはしに来る
遅い時間帯は右のはしで止まり、それ以上動かない
手で動かすと、10秒たってから戻る
日付を押すと、その場で今の時刻へ戻る

ルール⑤⑥ 予約を押したときに出るもの

全員に公開 → 件名・時間・主催者が出る
主催者だけ公開 → 件名は出ず、時間と主催者が出る
非公開 → 時間だけが出る
端末の設定が切ってある → 公開の範囲によらず時間だけ
件名が長い → 折り返して出る（全角100文字まで確認）
「閉じる」／外側を押す → タイムラインに戻る

ルール⑦ 削除のボタン

消せる予約 → 「予約削除」と「閉じる」が出る
消せない予約 → 「閉じる」だけが出る

ルール⑧ タイムラインが出ないとき（画面ごと入れ替わる）

空室・入室待ち・利用中 → 下にタイムラインが出る
利用不可 → ホーム画面ごと入れ替わり、タイムラインは出ない

ルール⑨⑩ よそでの変更・スリープからの復帰

よそで予約が作られる → 操作なしで帯が現れる
よそで予約が消される → 操作なしで帯が消える
よそで時間が変わる・伸びる・縮む → 帯もそれに合わせて動く
スリープから戻る → 今の時刻の位置に追いつく

通し（実機で最後まで）
