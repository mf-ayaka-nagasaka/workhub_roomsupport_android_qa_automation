# language: ja
機能: 個人コードで本人確認できる
  カメラ認証画面（予約認証モード用）で顔またはQRから人物が特定された後、追加の本人確認として個人コードの入力を求め、照合が成立したときだけ特定結果を次の画面へ引き渡す。人物の特定そのものと、特定結果を受け取った先の画面で行う処理は扱わない

  背景:
    前提 会議室タブレットは予約認証モードで設定されている

  # ※ 顔・QRによる人物の特定そのものは⑪⑫の責務（台帳 #38）
  # ※ カメラ認証画面に到達するかどうかの判定は⑪のルール⑨の責務（台帳 #55・#57）
  # ※ 一致しなかったときの失敗表示の見え方・認証待ちへの復帰は⑭の責務（台帳 #56）。ただし赤カード①の結論に依存する
  # ※ 入力中の無操作タイマー・30秒の認証タイムアウトは⑮の責務（台帳 #43）
  # ※ 入力画面・登録案内の言語切替はローカライズのチケットの責務
  # ※ 個人コードの登録そのもの（workhub Pass のマイページ）はアプリ外のため対象外
  # ※ 特定結果を受け取った先の画面で行う解錠・入退室の更新は⑳㉑㉓の責務
  # ※ 個人コードの入力を確定してから画面が切り替わるまでの応答時間は観点の要素に留めシナリオ化しない（PE-01・台帳 #58）
  # ※ 「操作ごとの画面」はホーム画面／予約作成の画面／延長時間を設定する画面のいずれか。どれになるかは⑪のルール②の責務
