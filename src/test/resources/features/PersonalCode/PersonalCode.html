PersonalCode ／ 全体マップ

個人コードで本人確認できる

カメラ認証画面で顔やQRから人が特定されたあと、個人コードの入力を求めるかどうかを決め、入力が合っていたときだけ次の画面へ進むまでを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝うまくいかないときの確認。

ルール① 入力画面が出る条件

要求する設定が有効・コード登録あり → 入力画面が出る
要求する設定が無効 → 入力画面は出ず、そのまま進む
コードを登録していない従業員 → そのまま進む
顔で特定されたとき → 入力画面が出る
QRコードで特定されたとき → 入力画面が出る

ルール② 入力したコードを照らし合わせる

登録が1件で、そのコードを入力 → 次の画面へ進む
登録が複数で、そのうち1つを入力 → 次の画面へ進む
違うコードを入力 → 入力画面に残り、もう一度入れ直せる
何も入れずに確定 → 合わなかったものとして扱われる

ルール③ 入力したコードの見え方

入力すると、文字数ぶん伏せ字で表示される
切り替えると、入れた文字がそのまま見える
もう一度切り替えると、伏せ字に戻る

ルール④ 登録していない人への案内

会員・エリアの設定が有効・登録なし → 登録の案内が出る
従業員・登録なし → 案内は出ず、そのまま進む
会員でもエリアの設定が無効 → 案内は出ず、そのまま進む

ルール⑤ 本人確認を終えずに戻る

入力画面で「トップに戻る」 → ホーム画面へ戻る
案内で「認証に戻る」 → カメラ認証画面の認証待ちへ戻る

ルール⑥ 調べられなかったとき

問い合わせがサーバーエラー・オフラインで失敗 → そのまま進む
