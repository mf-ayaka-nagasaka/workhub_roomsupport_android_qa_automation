## ルールの洗い出しと正常系・異常系の分類

### 機能名: 予約認証設定の変更
**機能概要:** 管理者が管理者メニューからタブレット設定画面を開き、予約認証モードに関連する全設定項目（基本設定・パスワード・認証・画面表示/機能制御・利用時間・デバイス/解施錠・SE/通知・顔認証）を変更して保存する。初期設定とは異なり、既存設定の編集フローであり、全項目に初期値が設定済みの状態から変更操作を行う。キャンセル操作や既存設定コピーが利用可能。

---

### ルール①: 管理者は予約認証モードの設定を変更して保存できる
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 設定変更→保存→遷移の一連のUI状態変化はViewModelのストリーム検証で完結するため。

| 対象 | 操作 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 管理者 | 設定変更して保存 | 🟢正常系：認証方法・予約作成可否・自動キャンセル等を変更して保存 | 変更内容が端末設定として保存される |
| 管理者 | 保存後の反映 | 🟢正常系：保存成功後のホーム画面・カメラ認証画面 | 変更が各画面にリアルタイムに反映される |
| 管理者 | 保存後の反映 | 🟢正常系：保存→コピー確認→完了後の管理者メニュー | 管理者メニューに戻る |
| 管理者 | 保存失敗 | 🟡例外系：設定保存APIが失敗 | エラー「タブレット情報の保存に失敗しました」が表示される |

---

### ルール②: 予約認証モードのスペース選択には予約設定のあるスペースのみ表示される
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** スペース一覧のフィルタリング表示はViewModelの状態変化であり、ストリーム検証で完結するため。

| 対象 | 認証モード | スペースの状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 管理者 | 予約認証 | 予約設定あり（通常予約またはサードプレイス） | 🟢正常系：予約設定のあるスペースがスペース選択項目に表示される | スペース選択項目に表示される |
| 管理者 | 予約認証 | 予約設定なし | 🟢正常系：予約設定のないスペースはスペース選択項目に表示されない | スペース選択項目に表示されない |

### ルール③: 顔認証を含まない認証方法では顔認証必須の機能を有効化できない

| 管理者 | 顔認証を含まない（QRのみ） | 予約作成（今すぐ入室） | 🔴異常系：QR認証のみで予約作成を有効化しようとする | エラー「『タブレットからの機能制御』>『予約作成（今すぐ入室）』が不適切です」が表示され、エラーダイアログ内に認証方法の変更導線が提示される |

### ルール⑨: ON/OFF切替で子項目の表示が連動する設定
**推奨テスト階層:** Presentation Unitテスト (JVM / Turbine)
**割り振り理由:** 親項目の切替に応じた子項目の表示/非表示はViewModelの状態変化であり、ストリーム検証で完結するため。

**ネスト構造（画面表示・機能制御セクション）:**
```
自動ステータス更新 = 有効
├── 自動キャンセル = 有効
│   ├── 自動キャンセル時間（秒）
│   └── 自動キャンセル前通知 = 有効
│       └── 前通知時間（秒）
└── 自動延長 = 有効
    ├── 自動延長タイミング（分）
    └── 延長時間（分）
```

**ネスト構造（SE・通知セクション）:**
```
終了前リマインダー = 有効
├── 通知時間（秒）
├── 繰り返し = 回数指定
│   └── リマインダー回数（回）
└── リマインダー音（Picker）
```

**ネスト構造（デバイス・解施錠セクション）:**
```
解錠機能 = 解錠する
├── 解錠対象デバイス1（Picker）
└── 解錠対象デバイス2（Picker）※Enterprise/ThirdPlace/BillTenantのみ

常時接続 = 有効
└── 常時接続対象デバイス（MultiPicker）
```

**ネスト構造（顔認証セクション ※isFaceOptionActive時のみ表示）:**
```
なりすまし防止 = 有効
├── 防止モード（ハイセキュリティ/スムーズ）
│   └── 判定方法の自動切替 ※ハイセキュリティ時のみ
└── なりすまし防止期間
```

**ネスト構造（画面表示・機能制御セクション - 省エネモード）:**
```
省エネモード = カスタム
├── 開始バッテリー残量（Picker）
├── 開始温度状態（Picker）
├── 停止バッテリー残量（Picker）
└── 停止温度状態（Picker）
```

| 親項目（セクション） | 操作 | 子項目 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 自動ステータス更新（画面表示・機能制御） | 有効にする | 自動キャンセル、自動延長（配下すべて） | 🟢正常系：無効→有効に切替 | 自動キャンセル・自動延長の設定項目群が表示される |

| 自動キャンセル前通知 | 有効にする | 前通知時間（秒） | 🟢正常系：無効→有効に切替 | 前通知時間の入力欄が表示される |

| リマインダー繰り返し | 回数指定にする | リマインダー回数（回） | 🟢正常系：無限→回数指定に切替 | 回数入力欄が表示される |
