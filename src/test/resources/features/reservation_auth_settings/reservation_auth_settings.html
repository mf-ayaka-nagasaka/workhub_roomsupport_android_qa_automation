予約認証の設定を変更して保存する

管理者メニューから設定変更画面を開いて、予約に使う認証の方法やルールを変え、保存して管理者メニューに戻るまでに裏で何が順番に起きるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

ルール① 設定を変更して保存する

設定を変えて保存 → 保存される
保存した後 → ホーム画面や認証画面に反映
保存に失敗 → エラーが出る

ルール② スペースの絞り込み

予約設定のあるスペースだけ表示される
予約設定のないスペースは表示されない

ルール③ 認証方法と機能の制限

顔認証を含む方法 → 予約作成が使える
QR認証のみ → 予約作成が使えない＋変更の案内
QR認証のみ → 予約削除が使えない＋変更の案内

ルール④ 入力のチェック

必須項目が空 → エラー詳細が出る
数値に0以下 → エラー
パスワード不一致 → エラー
複数セクションにエラー → バッジが出る

ルール⑤ キャンセル

キャンセル → 変更を捨てて管理者メニューへ

ルール⑥ コピーと完了

コピーして管理者メニューへ
コピーしないで管理者メニューへ
識別名称が空 → 登録できない
コピーの登録に失敗 → エラーが出る

ルール⑦ 常時接続推奨

「有効化する」を選ぶ → 常時接続ONで保存へ
「そのまま保存する」を選ぶ → 常時接続OFFで保存へ

ルール⑧ 既存設定コピー

テンプレートを選ぶ → 設定が上書きされる
端末設定を選ぶ → 設定が上書きされる
キャンセル → 今の入力が残る

通し（実機で最後まで）

管理者メニューから設定を変えて最後まで
