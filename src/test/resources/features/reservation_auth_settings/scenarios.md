# language: ja
機能: 予約認証設定の変更
  管理者が管理者メニューからタブレット設定画面を開き、
  予約認証モードに関連する設定（認証方法・予約作成可否・自動キャンセル等）を変更して保存する。

  背景:
    前提 タブレットは初期設定が完了済みであり、管理者メニューから設定変更画面にアクセスできる状態である

  # ────────────────────────────────────────
  # ルール①: 管理者は予約認証モードの設定を変更して保存できる
  # ────────────────────────────────────────

  # @TestLevel: PresentationUnit (JVM / Turbine)
  # 🟢 正常系：設定変更して保存成功
  シナリオ: 予約認証モードの設定を変更して保存できる
    前提 管理者 "田中" が設定変更画面で予約認証モードの設定を表示している
    もし 田中が認証方法・予約作成可否・自動キャンセル等の設定を変更して保存を実行する
    ならば 変更内容が端末設定として保存される

  # @TestLevel: PresentationUnit (JVM / Turbine)
  # 🟢 正常系：保存後の反映確認

    前提 管理者 "田中" が設定変更を保存して完了遷移を終えている
    ならば 変更がホーム画面およびカメラ認証画面にリアルタイムに反映される
