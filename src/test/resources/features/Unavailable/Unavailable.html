Unavailable ／ 全体マップ

利用不可・利用時間外を表示できる

会議室の前のタブレットが、1秒ごとに「いまこの部屋は使える時間か」を見直して、使えない時間になったらホームの中身をまるごと「利用不可の画面」に入れ替えるまでを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝できない・決まった言葉になるときの確認。

ルール① 使えない時間帯（一時停止スケジュール）

始まりの1分前 → まだ通常のホーム
始まりの時刻ちょうど → 操作なしで利用不可の画面になる
終わりの1分前 → まだ利用不可の画面
終わりの時刻ちょうど → 操作なしで通常のホームに戻る
時間帯が2つあるとき → 間は通常のホーム、次の始まりでまた入れ替わる
日付をまたぐ時間帯 → 0時を過ぎても利用不可の画面のまま
入室待ちの予約があっても → 利用不可の画面になり、入室できない
使っている最中でも → 利用不可の画面になり、退室できない（終了時刻に予約は自動で終わる）
見ている最中に時間帯が登録される → 再起動しなくても利用不可の画面になる
同じ部屋に2台、片方だけ登録 → 登録した端末だけが利用不可の画面になる

ルール② 予約に使える時間帯

始まりの1分前 → 利用不可の画面
始まりの時刻ちょうど → 通常のホームに戻る
終わりの時刻ちょうど → まだ通常のホーム
終わりの1分後 → 利用不可の画面になる
従業員向けは時間外でも、会員向けが時間内 → 通常のホーム
従業員向けも会員向けも時間外 → 利用不可の画面
会員向けだけ設定された部屋 → 時間内は通常のホーム、時間外は利用不可の画面
管理画面で時間帯を今の時刻を含むように変更 → 操作なしで通常のホームに戻る
予約を受け付けない部屋 → 時刻に関わらず終日 利用不可の画面

ルール③ 利用不可の画面に出るもの・出ないもの

空室から入れ替わる → ボタンも中央の輪も下の一覧も出ない
入室待ちから入れ替わる → 残り時間も参加者も出ない
入れ替わっても、上の部屋の名前と JP／EN の切替は残る

ルール④ 画面の真ん中に出る言葉

JP を選んでいる → 登録した日本語の言葉が出る
EN を選んでいる → 登録した英語の言葉が出る
日本語の言葉を空にした → 「利用時間外」が出る（空にはならない）
英語の言葉を空にした → 「Service is currently unavailable」が出る
利用不可の画面のまま JP → EN に切り替える → その場で言葉が変わる
入れられる上限いっぱいの長さ（100文字） → 欠けずに読める
端末の言語設定が英語でも、画面で JP を選んでいれば日本語の言葉が出る
画面を縦にしても横にしても → 100文字の言葉が欠けずに読める

ルール⑤ 2つの設定が重なるとき

使えない時間帯だけ当てはまる → 利用不可の画面
予約に使える時間帯の外だけ当てはまる → 利用不可の画面
両方とも当てはまる → 利用不可の画面
片方だけ終わっても → もう片方が残っていれば利用不可の画面のまま
両方とも使える状態に戻る → 通常のホームに戻る

通し（実機で最後まで）

使えない時間帯に入ると、操作しなくても利用不可の画面と理由の言葉が出る

画面に出る言葉で、どこの話かわかる

画面に出る言葉出てくる場所
登録した日本語の言葉（例：清掃中のため利用できません）④ 出す言葉を決める（JP を選んでいて、日本語の言葉が入っているとき）
登録した英語の言葉④ 出す言葉を決める（EN を選んでいて、英語の言葉が入っているとき）
利用時間外④ 出す言葉を決める（JP を選んでいて、日本語の言葉が空のとき）
Service is currently unavailable④ 出す言葉を決める（EN を選んでいて、英語の言葉が空のとき）
部屋の名前／JP・EN の切替⑤ 中身を入れ替える（入れ替えても上に残り続ける）
