# language: ja
機能: 利用不可・利用時間外を表示できる
  会議室のドア前に常設されたタブレットのホーム画面で、清掃・設備点検・営業時間外などその部屋を予約に使えない時間帯になったとき、画面全体を利用不可の画面に切り替えて、利用者に今は使えないことを伝える。利用者の操作を待たずに自動で切り替わり、時間帯が終わると自動で通常の表示に戻る

  背景:
    前提 会議室タブレットは予約認証モードで設定されており、起動準備を終えてホーム画面を表示している

  # ※ 管理画面の一時停止スケジュール中の表示（空室のまま主ボタンが消える）は⑦の責務（台帳 #33）。本機能では扱わない
  # ※ 利用不可のメッセージをタップしたときの読み込み直しは、参照元で意図的に何も起きない実装のため対象外（2026-11-11 合意）
