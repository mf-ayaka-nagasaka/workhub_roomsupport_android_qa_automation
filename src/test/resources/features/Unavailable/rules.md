## ルールの洗い出しと正常系・異常系の分類

### 機能名: 利用不可の表示

**機能概要:** 会議室のドア前のタブレットのホーム画面で、清掃・設備点検・営業時間外などその部屋を予約に使えない時間帯になったとき、画面全体を「利用不可」の表示に切り替えて、利用者に今は使えないことを伝える。利用者の操作を待たずに自動で切り替わり、時間帯が終わると自動で通常の表示に戻る。

**処理の順序:** ①1秒ごとに利用不可かどうかを判定する（まず端末の**一時停止スケジュール**、次に部屋の状態が「利用不可」かどうか） → ②どちらかに当てはまればホームの中身を**利用不可の画面**へ差し替える → ③**利用不可のメッセージ**に、設定された利用時間外メッセージを表示言語に応じて表示する → ④どちらにも当てはまらなくなると通常のホーム表示へ戻る。

**用語:**
- **利用不可の画面**：ホームの中身が差し替わった状態。画面上部のヘッダーと、画面中央の利用不可のメッセージだけになる。
- **利用不可のメッセージ**：利用不可の画面のとき、画面中央に出る文言。
- **ヘッダー**：画面上部の、ロゴ・空間名・JP/EN の言語切替が並ぶ帯。利用不可の画面でも残る。
- **一時停止スケジュール**：設定画面（基本設定）の利用時間の項目で登録する、開始日時と終了日時の組。「指定した期間、利用可能時間帯に関係なく利用できなくなります」。
- **予約可能時間帯設定**：管理画面のエリアの予約設定で、曜日ごとに登録する予約に使える時間帯。従業員向け（通常の予約設定）と会員向け（会員予約設定）がある。

**合否の判定:** 画面に**どの要素が出ているか・そこに何と書かれているか**で判定する。背景色は検証対象としない（⑦⑧⑨で決めた方針に合わせる）。

**責務の切り分け:** 以下は本機能の対象外とし、記載のチケットで検証する（`_master/feature-map.html` の決定台帳を参照）。

| 対象外とする処理 | 移管先のチケット | 台帳 |
| :--- | :--- | :--- |
| 一時停止スケジュール・利用時間外メッセージの入力・保存・文字数の制限 | 管理者が予約認証の設定を変更できる | — |
| 管理画面の一時停止スケジュール中のホームの表示（利用不可にはならず、空室の表示のまま主ボタンが消える） | 部屋の予約状況をホーム画面に表示できる | #33 |
| 空室・入室待ち・利用中の表示と、その切り替わり | 部屋の予約状況をホーム画面に表示できる | #5 #9 |
| 常時認証モード専用の利用時間外画面（ヘッダーが無く、タップも効かない画面） | — | #10 Android版では実装しないためスコープ外 |
| 常時認証モード専用の「利用可能時間帯（曜日別）」 | — | 予約認証モードでは設定画面に項目自体が出ず、QAが値を変えて確かめられないため検証対象外。受け入れ条件⑤「この設定に依存しない」は、ルール①②の正常系が通ることで結果的に担保される |
| 利用不可のメッセージをタップしたときの読み込み直し | — | 参照元（iOS）で意図的に何も起きない実装になっており、Android版もこれに準拠する。受け入れ条件④のうちタップの項目は対象外とする（2026-11-11 合意） |
| ロゴの長押しで管理者メニューを開く操作 | 管理メニューを開いて端末を管理できる | #14 |
| 表示言語を切り替える操作そのもの | 全画面共通 | #14 |
| 利用不可の画面に重ねて出る、終了前の通知・ネットワークが不安定な旨の通知・操作エラーの通知 | 予約終了リマインドを通知できる／オフライン時のフォールバックを設計・検討できる／各操作のチケット | — |
| 設置空間が組織側で削除されたとき／予約設定が未設定の部屋のホーム表示 | 未割り当て | #22 |

### ルール①: 一時停止スケジュールの時間帯に入ると、ホームは利用不可の画面に切り替わる

> 判定は1秒ごとに自動で行われ、利用者の操作は要らない。判定に使う時刻は端末の時計で、サーバ時刻とは同期しない（台帳 #36）。時間帯は**開始時刻ちょうどから終了時刻の直前まで**で、終了時刻ちょうどは時間帯の外になる。部屋に予約があっても、この時間帯のあいだは利用不可の画面が優先される。予約がある状態で時間帯が始まったときに何が表示されなくなるかは、ルール③で扱う。

| 対象 | 現在時刻と時間帯の関係 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| ホームの表示 | 開始時刻の1分前 | 🟢 正常系：当日に1件だけ時間帯を登録し、予約が無い状態で開始時刻の1分前になる | 空室の表示のまま変わらない |
| ホームの表示 | 開始時刻ちょうど | 🟢 正常系：同じ状態で開始時刻ちょうどになる | 利用者が何も操作しなくても、開始時刻を過ぎてから1秒以内に利用不可の画面に切り替わる |
| ホームの表示 | 終了時刻の1分前 | 🟢 正常系：時間帯の終了1分前になる | 利用不可の画面が続く |
| ホームの表示 | 終了時刻ちょうど | 🟢 正常系：終了時刻ちょうどになる | 利用者が何も操作しなくても、終了時刻を過ぎてから1秒以内に空室の表示に戻る |
| ホームの表示 | 2件の時間帯の間 | 🟢 正常系：時間帯を2件登録し、1件目が終わってから2件目の開始時刻になる | 1件目の終了で空室の表示に戻り、2件目の開始で再び利用不可の画面になる |
| ホームの表示 | 入室待ちの予約と重なる | 🟢 正常系：入室待ちの予約がある状態で時間帯の開始時刻になる | 入室待ちの表示から利用不可の画面に切り替わり、入室の操作ができなくなる |
| ホームの表示 | 利用中の予約と重なる | 🟢 正常系：予約に入室して利用中の状態で時間帯の開始時刻になる | 利用中の表示から利用不可の画面に切り替わり、退室の操作ができなくなる |
| ホームの表示 | 日付をまたぐ時間帯の中（日付が変わる直前） | 🟢 正常系：22:00〜翌 1:00 の時間帯を1件登録し、23:59 になる | 利用不可の画面が続く |
| ホームの表示 | 日付をまたぐ時間帯の中（日付が変わった直後） | 🟢 正常系：同じ状態で 0:00 になる | 日付が変わっても利用不可の画面が続く |
| ホームの表示 | 日付をまたぐ時間帯の終了時刻ちょうど | 🟢 正常系：同じ状態で 1:00 になる | 空室の表示に戻る |
| ホームの表示 | 表示中に、現在時刻を含む時間帯が新しく登録される | 🟢 正常系：13:30 にホームが空室を表示している状態で、設定画面から 13:00〜14:00 の時間帯を保存する | アプリを再起動しなくても、1秒以内に利用不可の画面に切り替わる |
| 2台の端末の表示 | 片方の端末にだけ時間帯が登録されている | 🟢 正常系：同じ部屋に2台設置し、片方の端末にだけ 13:00〜14:00 を登録して開始時刻になる | 登録した端末だけが利用不可の画面になり、もう一方は通常のホーム表示のまま操作できる |

### ルール②: 予約可能時間帯の外では、ホームは利用不可の画面になる

> 判定に使われるのは、管理画面のエリアの予約設定で登録する**予約可能時間帯設定**。従業員向けと会員向けのどちらか一方でも現在時刻がその時間帯の中なら通常の表示になり、**両方とも外のときだけ**利用不可の画面になる。
> 一時停止スケジュール（ルール①）とは終わり際の扱いが逆で、一時停止スケジュールは終了時刻ちょうどで時間帯の外になるのに対し、**予約可能時間帯は終了時刻ちょうどはまだ時間帯の中**になる。
> 管理者が意図して「予約を受け付けない」設定にしている部屋は本ルールで扱う（台帳 #37）。予約設定そのものが**未設定**の部屋は、設置空間の不備と同じ系統の別論点（台帳 #22）のため本機能では扱わない。

| 対象 | 従業員向けの予約可能時間帯 | 会員向けの予約可能時間帯 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| ホームの表示 | 中 | 未設定 | 🟢 正常系：従業員向けだけが設定された部屋で、時間帯の中の時刻にホームを表示する | 空室の表示になる |
| ホームの表示 | 外（開始時刻の1分前） | 未設定 | 🟢 正常系：時間帯の開始1分前の時刻にホームを表示する | 利用不可の画面になる |
| ホームの表示 | 中（開始時刻ちょうど） | 未設定 | 🟢 正常系：開始時刻ちょうどになる | 利用者が何も操作しなくても、1秒以内に空室の表示に切り替わる |
| ホームの表示 | 中（終了時刻ちょうど） | 未設定 | 🟢 正常系：終了時刻ちょうどになる | 空室の表示のまま変わらない |
| ホームの表示 | 外（終了時刻の1分後） | 未設定 | 🟢 正常系：終了時刻の1分後になる | 1秒以内に利用不可の画面に切り替わる |
| ホームの表示 | 未設定 | 中 | 🟢 正常系：会員向けだけが設定された部屋で、時間帯の中の時刻にホームを表示する | 空室の表示になる |
| ホームの表示 | 未設定 | 外 | 🟢 正常系：同じ部屋で、時間帯の外の時刻にホームを表示する | 利用不可の画面になる |
| ホームの表示 | 外 | 中 | 🟢 正常系：従業員向けと会員向けの両方が設定された部屋で、従業員向けの時間帯の外・会員向けの時間帯の中の時刻にホームを表示する | 空室の表示になる（利用不可にはならない） |
| ホームの表示 | 外 | 外 | 🟢 正常系：同じ部屋で、どちらの時間帯からも外れた時刻にホームを表示する | 利用不可の画面になる |
| ホームの表示 | 外 → 中（管理画面で変更） | 未設定 | 🟢 正常系：利用不可の画面を表示している状態で、管理画面から現在時刻を含むように予約可能時間帯を変更する | 利用者が何も操作しなくても、1秒以内に空室の表示に戻る |
| ホームの表示 | 予約を受け付けない（管理画面で無効にしている） | 未設定（会員予約設定を使わない部屋） | 🟡 例外系：管理画面で従業員向けの予約設定を「予約を受け付けない」にした部屋でホームを表示する | 時刻にかかわらず、終日利用不可の画面のままになる |

### ルール③: 利用不可の画面に出るのは、ヘッダーと利用不可のメッセージだけ

> ホームの中身がまとめて差し替わるため、主ボタン・サブボタン・中央サークル・参加者情報エリア・画面下部のタイムラインはどれも表示されない。ヘッダーだけは残る。

| 対象 | 切り替わる前の状態 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- |
| 利用不可の画面 | 空室 | 🟢 正常系：予約が無く空室の状態で、設定画面に登録した一時停止スケジュール 13:00〜14:00 の開始時刻（13:00）になる | ヘッダーと利用不可のメッセージだけになり、主ボタン「今すぐ入室」・中央サークル・画面下部のタイムラインは表示されない |
| 利用不可の画面 | 入室待ち | 🟢 正常系：参加者が登録された予約が入室待ちの状態で、設定画面に登録した一時停止スケジュール 13:00〜14:00 の開始時刻（13:00）になる | 主ボタン「入室」・サブボタン「予約削除」・中央サークルの残り時間・参加者情報エリア・タイムラインがいずれも表示されない |
| 利用不可の画面 | 利用中 | 🟢 正常系：予約に入室して利用中の状態で、設定画面に登録した一時停止スケジュール 13:30〜14:00 の開始時刻（13:30）になる | 主ボタン「退室」・サブボタン「予約延長」「再入室」がいずれも表示されない |
| ヘッダー | 利用不可 | 🟢 正常系：一時停止スケジュール 13:00〜14:00 を登録した端末で、13:30 にホームを表示する | ヘッダーは残り、空間名が表示され、JP/EN の言語切替が操作できる |

### ルール④: 利用不可のメッセージには、設定された利用時間外メッセージが表示言語に応じて表示される

> 表示する文言は、**ヘッダーの JP/EN で選ばれている表示言語**に対応するほうの利用時間外メッセージ（設定画面で登録する）。そちらが空のときは、言語ごとの既定の文言（日本語「利用時間外」／英語「Service is currently unavailable」）が出る。端末のロケールは見ていない（台帳 #34）。

| 対象 | 表示言語 | 利用時間外メッセージの設定 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| 利用不可のメッセージ | JP | 日本語・英語とも登録済み | 🟢 正常系：日本語に「清掃中のため利用できません」、英語に別の文言を登録し、一時停止スケジュール 13:00〜14:00 を登録した端末で JP を選んだ状態で 13:30 にホームを表示する | 「清掃中のため利用できません」が表示される |
| 利用不可のメッセージ | EN | 日本語・英語とも登録済み | 🟢 正常系：同じ設定・同じ時間帯で EN を選んだ状態で 13:30 にホームを表示する | 登録した英語の文言が表示される |
| 利用不可のメッセージ | JP | 日本語を空にして保存 | 🔴 異常系：日本語の利用時間外メッセージを空にして保存し、同じ時間帯で JP を選んだ状態で 13:30 にホームを表示する | 文言が空にならず、「利用時間外」が表示される |
| 利用不可のメッセージ | EN | 英語を空にして保存 | 🔴 異常系：英語の利用時間外メッセージを空にして保存し、同じ時間帯で EN を選んだ状態で 13:30 にホームを表示する | 文言が空にならず、「Service is currently unavailable」が表示される |
| 利用不可のメッセージ | JP → EN | 日本語・英語とも登録済み | 🟢 正常系：利用不可の画面になっている状態で、ヘッダーの言語切替を JP から EN に切り替える | その場で表示が英語の文言に変わる |
| 利用不可のメッセージ | JP（端末の言語設定は英語） | 日本語・英語とも登録済み | 🟢 正常系：端末の言語設定を英語にしたタブレットで、ヘッダーの言語切替は JP のまま利用不可の画面にする | 端末の言語設定にかかわらず、日本語の文言が表示される |
| 利用不可のメッセージ | JP | 日本語に上限ちょうどの100文字を登録 | 🟢 正常系：100文字ちょうどの文言を登録し、JP を選んだ状態で利用不可の画面にする | 登録した100文字が欠けずに表示される |
| 利用不可のメッセージ | JP | 日本語に上限ちょうどの100文字を登録 | 🟢 正常系：同じ設定で、画面の向きを縦・横それぞれにして利用不可の画面にする | どちらの向きでも文言が欠けずに読める |

### ルール⑤: 一時停止スケジュールと予約可能時間帯のどちらか一方でも利用できない時間帯なら、ホームは利用不可の画面になる

> ルール①とルール②の判定は、**どちらか一方でも「使えない」に当てはまれば利用不可**という組み合わせ方になっている。両方とも利用できる状態に戻って初めて、通常のホーム表示へ戻る。

| 対象 | 一時停止スケジュール | 予約可能時間帯 | 実例（データ・状況の組み合わせ） | 期待される振る舞い |
| :--- | :--- | :--- | :--- | :--- |
| ホームの表示 | 時間帯の中 | 中 | 🟢 正常系：一時停止スケジュール 13:00〜14:00、予約可能時間帯 9:00〜18:00 の部屋で 13:30 になる | 一時停止スケジュールだけが当てはまっても利用不可の画面になる |
| ホームの表示 | 時間帯の外 | 外 | 🟢 正常系：同じ部屋で 18:30 になる | 予約可能時間帯だけが当てはまっても利用不可の画面になる |
| ホームの表示 | 時間帯の中 | 外 | 🟢 正常系：一時停止スケジュール 17:30〜18:30、予約可能時間帯 9:00〜18:00 の部屋で 18:10 になる | 両方とも当てはまるので利用不可の画面になる |
| ホームの表示 | 時間帯の外（終了した直後） | 外 | 🟢 正常系：同じ部屋で 18:30 になる（一時停止スケジュールだけが終わる） | 予約可能時間帯の外のままなので、利用不可の画面が続く |
| ホームの表示 | 時間帯の中 | 中（始まった直後） | 🟢 正常系：一時停止スケジュール 8:00〜10:00、予約可能時間帯 9:00〜18:00 の部屋で 9:00 になる（予約可能時間帯だけが始まる） | 一時停止スケジュールの時間帯が続いているので、利用不可の画面が続く |
| ホームの表示 | 時間帯の外（終了した直後） | 中 | 🟢 正常系：同じ部屋で 10:00 になる（両方とも利用できる状態になる） | 1秒以内に空室の表示に戻る |
