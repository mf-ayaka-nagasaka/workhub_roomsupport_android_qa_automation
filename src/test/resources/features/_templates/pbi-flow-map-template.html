タブレットにログインして組織を選択できる

ログインボタンを押してから「設定読み込み画面」に着くまでに、裏で何が順番に起きるかを1枚にしたもの。図の箱やテストケースをクリックすると、対応する場所が光ります。

箱をクリックすると、その場所に関係するテストだけが残ります

テストケースは、図のどこの話？

カードをクリックすると図の該当箇所が光ります。図の箱をクリックすると、その箱に関係するカードだけが残ります。● 緑＝うまくいく確認、● 赤＝失敗したときの確認。

起動したとき

保存がない状態で起動 → ログイン画面
保存がある状態で起動 → 自動でログインが戻る

ルール① ログインする

正しい情報・所属1組織 → そのまま完了画面へ
正しい情報・所属が複数 → 組織選択画面へ
未登録メール／パスワード違い → エラー
未入力 → ボタンが押せない
メールの形式が変 → エラー
オフラインでログイン → エラー（送る前に止まる）
処理の途中で通信が切れる → エラー
アカウント情報が欠けている → エラー
パスワードを何回も間違える → ロック
ロック中にログイン → エラー
退職済み（どこにも所属なし） → エラー

ルール② 組織を選ぶ

組織を選んで確定 → 完了画面へ
未選択 → ボタンが押せない
組織選択画面でログアウト → ログイン画面へ
確定した後に通信が切れる → エラー
組織選択画面で強制終了 → 再起動で組織選択画面
④が終わる前に強制終了 → 再起動で組織選択画面
④が終わった後に強制終了 → 再起動で完了画面へ
選んだ組織で退職済み → エラー
止めている間に所属が変わった → 最新の一覧

通し（実機で最後まで）

所属1組織で最後まで
所属が複数で、選んで最後まで

エラーの言葉で、止まった場所がわかる

画面に出る言葉止まった場所
メールアドレスの形式が不正ですログイン画面（送る前）
インターネットに接続されていませんログイン画面（送る前） ／ ④ 確定した後
メールアドレスまたはパスワードに誤りがあります② 本人確認
アカウントがロックされているためログインできません② 本人確認
認証中にネットワークエラーが発生しました② 〜 ⑥ の途中
組織に所属していないためログインできません③ 0件のとき ／ ⑤ 選んだ組織で退職済みのとき
