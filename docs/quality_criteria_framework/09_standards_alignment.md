## 1. このドキュメントの位置づけ

本フレームワークの手順（利用文脈の確定 → 指標の引き当て → 閾値と合否ラインの合意 → 照合）は、**独自に発明したものではありません。** ISO/IEC 25000 シリーズ（SQuaRE）が定める品質モデル・品質測定・品質評価の枠組みに沿っています。本書はその対応関係を一覧にしたものです。

次の2つの場面で使います。

| 場面 | 使い方 |
|---|---|
| 社内への導入説明 | 「案件固有の手順ではなく標準ベースである」ことを示します |
| 社外・顧客への説明 | 品質保証の進め方の根拠として、本書をそのまま提示します |

### 「準拠（conformance）」とは記載しません

本フレームワークは、**ISO/IEC 25000 シリーズに基づいて（based on）設計したもの**です。適合性評価・審査を受けていないため、「ISO/IEC 25010 準拠」「ISO 準拠のフレームワーク」といった表現は使用しません。社外資料でも同様です。

規格本文は有償であり、本書には特性名・位置づけの要約のみを記載し、**定義文の転載は行っていません。** 正確な定義は §7 の出典から各規格を参照してください。

### 名称について（規格の用語に合わせています）

本フレームワークの成果物名と中核用語は、**JIS X 25041:2015（ISO/IEC 25041:2012）の表記をそのまま使っています。** 独自の通称ではありません。

| 本フレームワークの要素 | 規格上の用語 | 出典 |
|---|---|---|
| **文書全体**（基準合意時） | 評価計画（書）／製品品質評価計画（書） | JIS X 25041 序文・7.4.2 |
| **文書全体**（判定結果の記入後） | 評価報告書／製品品質評価報告書 | JIS X 25041 序文・7.6.3 |
| §4 の**基準値**列 | 品質測定量に対する判定基準 | JIS X 25041 7.3.3 |
| §5 の**総合判定** | 製品品質総合評価に対する判定基準 | JIS X 25041 7.3.4・7.4.2 |

> `acceptance criteria`（受入基準）とは別の概念です。区別は 01 §4 にあります。

**「判定基準」と「判断基準」はどちらも公式表記です。** JIS X 25041 は条項見出しで一貫して「判定基準」を使い（7.3.3 / 7.3.4 / 7.5.3 / 7.5.4）、JIS X 25040 は箇条4の定義語として「判断基準」（`decision criteria`、4.10）を置いています。規格シリーズ内で表記が揺れているため、**本書は条項見出し側の「判定基準」に揃えています。**

> JIS X 25040 4.10 の定義：「アクション若しくは追加調査の必要性を決めるため又は与えられた結果の信頼度のレベルを記述するために使う，しきい（閾）値，目標又はパターン。」（出典注記：JIS X 0141:2009）

**「品質基準」は規格の定義用語ではありません。** JIS X 25040 5.3 や JIS X 25041 5.3.1 に「要求された品質基準」という表現は現れますが、用語定義には含まれず、文脈も取得者が設定する要求水準（品質要求、ISO/IEC 25030）寄りです。本書では採用しません。呼称のバリエーションは 01 §1 を参照してください。

**版について。** JIS X 25040 は 2026-08-20 に改正されています（JIS X 25040:2026＝「品質評価の枠組み」、ISO/IEC 25040:2024 に対応）。本書の引用は 2014 年版（＝ISO/IEC 25040:2011）と JIS X 25041:2015 で確認した内容です。

## 4. 標準に該当がなく、自組織ルールとして補った部分

標準は**評価の枠組みまで**を定めており、評価結果を受けて**組織がどう意思決定するか**は規定していません。本フレームワークは以下をその空白に対する自組織ルールとして定義しています。社外説明でも、この区別を明示してください。

| 要素 | 収録場所 | 標準に該当がない理由 |
|---|---|---|
| **判定ラベル P1 / P2 / P3** | 02 §1 | 「未達のときリリースを止めるか」は組織の意思決定ルールであり、品質モデル・測定の範囲外です |
| **逸脱承認フロー** | 02 §5 | 基準未達のまま提供する際の承認手続きは、組織のガバナンスに属します |
| **文脈タグによる指標の引き当て** | 03 §4 / 04 §7 | 利用文脈を記述する考え方は標準にありますが、タグ化して指標母集団を機械的に絞る手法は本フレームワーク固有です |
| **不具合重要度との接続（FS-01 / FS-02 / FS-12）** | 06 | 不具合の重要度定義は各組織の品質保証ルールに属し、SQuaRE の測定量ではありません |
| **根拠区分** | 02 §8 | 閾値の出所を分類して記録する運用は本フレームワーク固有です |
| **判定タイミングの5分類** | 02 §2 | 「いつ測るか」の類型化は、評価の実施計画を具体化するための独自の整理です |

### 規格の記載項目のうち、本フレームワークが扱わないもの

JIS X 25041 7.4.2 は、評価計画書に次を「含むことが望ましい」としています（**要求事項ではなく推奨事項です**）。本フレームワークは品質判定そのものに範囲を絞るため、以下は様式に含めていません。プロジェクト管理の文書側で扱ってください。

| 規格の記載項目 | 本フレームワークでの扱い |
|---|---|
| 評価予算 | **扱いません**（プロジェクト計画側） |
| 評価マイルストンの設定及びその間の予定 | **扱いません**（テスト計画側。05 §4 の「判定タイミング」で代替します） |
| 評価に関与する組織 | 簡略化。01 §3 の責務定義と 05 §1 の合意者欄で代替します |

> **これらは標準の不足ではありません。** 標準が意図的に組織裁量としている領域です。「標準に基づく部分」と「組織が決めた部分」を分けて示すこと自体が、説明の信頼性になります。

## 5. 扱う範囲と扱わない範囲

### ISO/IEC 25019:2023（利用時品質）は扱いません

25019 は、製品が**実際に使われている状況で**利害関係者にどう影響するかを扱うモデルです。本フレームワークは**リリース前の内部ゲート**を対象としており、以下の理由から 25019 をスコープに含めません。

- リリース判定時点では実利用のデータが存在せず、観測可能性（01 §1）の要件を満たせません
- 実運用下の品質は SLA / SLO として別に扱われます（01 §4 で品質評価計画書と区別しています）

利用時品質を扱う必要がある場合は、本フレームワークの外側（運用監視・SLO）で定義してください。

### 製品品質モデル（25010:2023）の9特性はすべて分類軸に含みます

ただし、**各リリースで9特性すべてを判定対象にするわけではありません。** 扱わない特性は 02 §7 のスコープ宣言で明示的に記録します。

## 6. 指標の出自（`standard_ref`）

指標カタログの各指標には、出自を示す `standard_ref` を付与しています（03 §5）。顧客説明では、この列によって「どの指標が標準由来で、どれが組織の判断か」を指標単位で示せます。

| 値 | 意味 | 件数 |
|---|---|---|
| `ISO/IEC 25023 相当` | 25010 の特性に対する一般的な測定量として、標準側にも同型の測定量があるもの | 32 |
| `ISO/IEC 25059 相当` | AI固有の副特性（25059）に対応する類型のもの。**AQ指標群（10 §5）のみ**で、本カタログの59指標には含まれません | （10） |
| `プラットフォーム規定` | プラットフォーム提供元が公開するしきい値・API に基づくもの（Android Vitals / Google Play / Core Web Vitals） | 5 |
| `W3C WCAG 2.2` | Web アクセシビリティ標準に基づくもの | 2 |
| `OWASP` | OWASP の公開資料に基づくもの | 1 |
| `組織固有` | 上記に対応がなく、本フレームワークまたは導入組織が定めたもの | 19 |

> **`ISO/IEC 25023 相当` は「規格に同じ指標が載っている」という意味ではありません。** 規格本文は有償のため個別の測定量との一対一対応は検証しておらず、「標準に同型の測定量が存在する類型である」ことを示す区分です。

### 25023 に対応がない特性について

**ISO/IEC 25023:2016 は、ISO/IEC 25010:2011（8特性）を前提に作られています。** 2023年版で新設・再編された以下については、25023 側に対応する測定量がありません。

| 特性 | 状況 |
|---|---|
| **安全性（Safety）** | 2023年版で新設。SA-01〜SA-03 はすべて `組織固有` です |
| **柔軟性（Flexibility）** | 2023年版で新設。ただし導入性・置換性は 2011年版の移植性（Portability）に由来するため、FL-01〜FL-03 は `ISO/IEC 25023 相当` としています |
| **相互作用機能（Interaction Capability）** | 2011年版の使用性（Usability）を再編したもの。測定量の類型は引き継がれています |

25023 の改訂により 25010:2023 への対応が示された場合は、本節と `standard_ref` の見直しが必要です（§8）。

## 8. 標準の改訂ウォッチ

規格の版が変わると本書の記述が陳腐化します。以下を定期的に確認してください（確認の担当と頻度は組織プロファイル §8 に記録します）。

| 対象 | 確認すること | 影響範囲 |
|---|---|---|
| **ISO/IEC 25023** | 25010:2023 に対応した改訂が出ていないか | §6 の `standard_ref` 区分、安全性・柔軟性の扱い |
| ISO/IEC 25010 | 次版の有無 | 01 §7 の特性一覧、分類軸全体 |
| ISO/IEC 25040 | 次版の有無 | §3 の対応表 |
| **ISO/IEC 25041** | 次版の有無（**JIS X 25041 は 2015年版のまま**。ISO 側は 2012年版） | §1 の名称対応、§3 の対応表、05 の様式 |
| **ISO/IEC 25059** | **改訂版の発行状況**（第2版が DIS 段階。公開審査の終了日は無償資料では確認できていません） | 10. AI拡張 の全体（§3 副特性一覧、AQ指標の `standard_ref`） |
| プラットフォーム規定 | Android Vitals / Core Web Vitals のしきい値変更 | 該当指標の推奨初期値（03） |
| WCAG | 次版（WCAG 3.0 等）の勧告状況 | IC-03 / IC-04 |

> 「準拠」と書いていないため、改訂によって直ちに記述が誤りになることはありません。ただし**版を明記している以上、古い版を参照したままにしないでください。**
