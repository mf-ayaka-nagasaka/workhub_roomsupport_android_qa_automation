# 組織プロファイル（記入テンプレート）

| 項目 | 内容 |
|---|---|
| **象限** | 📗 リファレンス（記入テンプレート） |
| **対象者** | フレームワークを自組織に導入する方（QAリード／品質管理責任者） |
| **ゴール** | 組織固有の設定を1枚に集約し、フレームワーク本体を書き換えずに運用を開始できるようになります |

本フレームワークの**本体ドキュメント（00〜08）は組織に依存しない内容**になっています。組織・プロダクトごとに異なる情報は、すべて本ファイルに集約します。

**使い方:** 本ファイルを複製し、自組織用のページ・ファイルとして記入してください。記入後は、判定基準ドキュメント（05）のコンテキストサマリから本ファイルを参照します。

> **未記入の節を残さないでください。** 埋まっていない節があると、その節に依存する判定基準が書けません。各節の冒頭に、埋まらないと何が書けなくなるかを記載しています。

## 3. 承認者ロールのマッピング

> **埋まらないと書けないもの:** 逸脱承認フロー（02 §5）の運用。未達のままリリースする際に誰の承認を取るかが決まりません。

フレームワーク本体は**責務名**で記述しています。自組織の実際の役職名・体制を記入してください。

| 責務名 | 責務の内容 | 自組織での役職名・担当 |
|---|---|---|
| **プロダクト意思決定責務** | プロダクトの提供可否を最終判断する | |
| **技術判断責務** | 未達の技術的影響範囲とリスクを評価する | |
| **品質判断責務** | 測定の妥当性と品質リスクを評価する | |

記入例：プロダクト意思決定責務＝PdM（プロダクトオーナー）／技術判断責務＝開発リーダー／品質判断責務＝QA担当
