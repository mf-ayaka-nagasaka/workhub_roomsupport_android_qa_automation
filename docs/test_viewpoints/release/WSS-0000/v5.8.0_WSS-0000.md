# v5.8.0_WSS-0000: 一時停止スケジュール期間中の画面タップ時の遷移制御

## 修正内容
一時停止スケジュール期間中に画面タップした場合にステータス画面に遷移しないようにする（利用時間外画面にすぐに戻ること）

## 前提条件
- 予約認証モード
- 利用時間外中
- アプリ起動時

## QAで見ておきたいポイント
1. 画面タップ時にステータス画面が表示されないこと（利用時間外画面にすぐに戻ること）
   - 空室/入室待ち
   - 予約情報あり/なし
2. 利用時間外から内に切り替わった際に予約情報が正しく表示されること
   - 空室/入室待ち
   - 当日中/日跨ぎで利用時間外から内

## 不具合概要
- 予約認証モードで、一時停止スケジュール期間中に画面タップすると空室ステータス画面へ一時的に遷移する
- 予約認証モードは利用時間外中もタップで予約情報の更新が入る仕様だが、空室ステータス画面が表示されるべきではないと判断

## 不具合詳細
- **重要度**: Normal（不要な表示がある）
- **潜在区分**: 潜在（v4.6.0でも再現）
- **再現率**: 3/3
- **再現手順**: 一時停止スケジュール期間中に画面をタップする
- **再現結果**: 空室ステータス画面へ一時的に遷移する
- **期待する結果**: 空室ステータス画面が表示されないこと
